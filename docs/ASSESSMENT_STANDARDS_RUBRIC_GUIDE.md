# 4학년 국어 신문 읽기 성취기준·평가기준 정리

> 정리일: 2026-08-29  
> 적용 대상: 과정 중심 평가 보드 `4학년 신문읽기 내용이해`  
> 설계 원칙: 평가 설계 단계에서는 점수를 정하지 않고, 평가 요소·관찰 증거·성취수준을 먼저 확정한다.

## 1. 수업 맥락

- 학년: 초등학교 4학년
- 교과: 국어
- 활동명: 4학년 신문읽기 내용이해
- 수업 맥락: 다양한 신문기사를 읽으며 글의 내용과 의미를 이해한다.
- 평가 목표: 다양한 신문기사를 읽고 글의 의미와 중심 생각을 파악하며, 필요한 경우 기사 내용과 자신의 생각을 근거 있게 연결하여 표현하는 과정을 평가한다.

## 2. 성취기준

### 현재 평가 설계에 선택된 기준

| 구분 | 성취기준 | 평가에서 확인할 내용 |
| --- | --- | --- |
| 선택 | `[4국02-01]` 글의 의미를 파악하며 유창하게 글을 읽는다. | 학생이 글의 의미와 핵심 내용을 정확하게 파악하는지 확인한다. |
| 선택·코드 확인 필요 | 글의 중심생각을 찾을 수 있다. | 학생이 중심 생각과 이를 뒷받침하는 핵심 정보를 구분하는지 확인한다. |

두 번째 기준은 현재 보드에 코드 없이 저장되어 있다. 교육과정 라이브러리에서 정확한 성취기준 코드와 원문을 확인한 뒤 확정한다.

### 의견 쓰기 활동으로 확장할 때의 관련 기준

`[4국02-04]` 글을 읽고 사실과 의견을 구분하며, 필자와 자신의 의견을 비교한다.

이 기준은 기사 내용과 자신의 생각을 비교하거나 댓글·의견문을 쓰는 활동에서 사용한다. 단순 내용 이해 활동에는 자동으로 섞지 않고, 수업 과제에 비교·의견 표현이 실제로 포함될 때 선택한다.

## 3. 평가기준 설계 원칙

1. 점수보다 학생 결과물에서 직접 확인할 수 있는 관찰 증거를 먼저 정한다.
2. 성취기준과 수업 맥락에 모두 연결되는 평가 요소만 사용한다.
3. 학생의 찬성·반대 입장이 아니라 이해, 연결, 근거 표현의 질을 평가한다.
4. 각 요소는 `매우 잘함·잘함·보통·더 연습 필요`의 네 수준으로 기술한다.
5. 수준별 문장은 추상적인 인상 대신 학생이 실제로 한 행동과 결과물의 특징을 나타낸다.
6. AI 평가는 학생 답안에 드러난 근거만 사용하고, 제공되지 않은 원문이나 배경정보를 추측하지 않는다.

## 4. 평가 요소와 성취수준

### 평가 요소 1. 자료 탐색과 이해

- 평가 초점: 수업 과제에 필요한 사례나 자료를 찾아 핵심 내용을 정확하게 이해하는가?
- 관찰 증거: 필요한 사례나 자료를 찾고, 핵심 내용을 자기 말로 정리하여 결과물에 활용한 부분

| 성취수준 | 평가기준 |
| --- | --- |
| 매우 잘함 | 자료의 핵심 내용과 중요한 정보를 정확하게 이해하고, 자신의 말로 정리하여 결과물에 구체적으로 활용한다. |
| 잘함 | 자료의 핵심 내용을 대체로 정확하게 이해하고, 관련 정보를 결과물에 활용한다. |
| 보통 | 자료 내용의 일부를 이해하지만 핵심 내용이 빠지거나 중요한 정보의 활용이 부족하다. |
| 더 연습 필요 | 자료 내용을 잘못 이해했거나 자료와 관련된 내용이 결과물에 거의 나타나지 않는다. |

### 평가 요소 2. 중심 내용 파악

- 평가 초점: 글이나 자료의 중심 내용과 핵심 정보를 정확히 파악하는가?
- 관찰 증거: 글의 중심 생각, 핵심 정보, 세부 내용을 구분하고 자기 말로 정리한 부분

| 성취수준 | 평가기준 |
| --- | --- |
| 매우 잘함 | 글의 중심 생각과 중요한 정보를 정확하게 파악하고, 세부 내용과의 관계까지 자신의 말로 분명하게 설명한다. |
| 잘함 | 글의 중심 생각과 중요한 정보를 대체로 정확하게 파악하여 정리한다. |
| 보통 | 글의 일부 내용은 이해하지만 중심 생각과 세부 내용을 구분하는 데 어려움이 있다. |
| 더 연습 필요 | 글의 중심 생각을 잘못 파악했거나 핵심 내용이 결과물에 거의 나타나지 않는다. |

### 평가 요소 3. 근거 있는 생각 표현

- 평가 초점: 자신의 생각을 자료의 내용과 연결하여 근거 있게 표현하는가?
- 관찰 증거: 자신의 의견을 밝히고 글이나 자료의 내용과 연결한 이유를 제시한 부분

| 성취수준 | 평가기준 |
| --- | --- |
| 매우 잘함 | 자신의 의견이 분명하며, 자료에서 찾은 내용이나 구체적인 이유를 근거로 들어 설득력 있게 표현한다. |
| 잘함 | 자신의 의견과 그 이유를 비교적 분명하게 표현하고, 자료의 내용과 자연스럽게 연결한다. |
| 보통 | 자신의 의견은 나타나지만 이유나 근거가 부족하거나 자료와의 연결이 충분하지 않다. |
| 더 연습 필요 | 자신의 의견이 불분명하거나 이유와 근거가 거의 나타나지 않는다. |

## 5. 의견 쓰기 수업의 확장 평가 요소

### 기사와 자신의 생각 연결

이 요소는 `[4국02-04]`를 선택하고 기사 의견 쓰기 과제를 수행할 때 추가한다.

- 평가 초점: 기사 내용과 자신의 생각·경험·지식을 의미 있게 비교하고 연결하는가?
- 관찰 증거: 기사 내용, 자신의 경험이나 지식, 자신의 판단 사이의 관계를 설명한 부분

| 성취수준 | 평가기준 |
| --- | --- |
| 매우 잘함 | 기사 내용과 자신의 생각·경험·지식을 구체적으로 비교하고, 서로의 관계를 분명하게 설명한다. |
| 잘함 | 기사 내용과 자신의 생각을 자연스럽게 연결하여 표현한다. |
| 보통 | 자신의 생각은 나타나지만 기사 내용과의 연결이나 비교가 약하다. |
| 더 연습 필요 | 자신의 생각과 기사 내용의 관계가 거의 나타나지 않는다. |

## 6. 보드와 AI 평가에 적용하는 방법

1. 교사는 학년·교과·수업 맥락을 저장한 뒤 실제 수업에 맞는 성취기준을 선택한다.
2. 보드는 선택한 성취기준과 수업 맥락을 바탕으로 평가 요소를 추천한다.
3. 교사는 평가 요소별 관찰 증거와 네 단계 성취수준을 검토·수정하고 평가 설계를 확정한다.
4. 평가지 문항마다 실제로 관찰할 평가 요소만 연결한다.
5. AI는 저장된 평가지 문항, 학생 답안, 연결된 평가 요소의 성취수준을 함께 읽고 평가 초안을 만든다.
6. AI는 답안에 없는 사실을 추측하거나 `원문이 없어 확인하기 어렵다` 같은 일반 문구를 반복하지 않고, 학생 답안에서 확인되는 내용에 집중한다.
7. 교사는 AI 초안의 근거와 성취수준 판단을 확인한 뒤 최종 평가를 확정한다.
