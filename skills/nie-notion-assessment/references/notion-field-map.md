# Notion 필드 매핑

DB 구조가 다르면 교사에게 매핑을 확인한 뒤 이 표를 갱신해서 쓴다.
**필드 이름이 확실하지 않으면 추측해서 쓰지 않는다.**

## A. 학생 제출물 평가 관리 DB

| 필드 | 유형 | 구분 | 이 스킬의 권한 |
| --- | --- | --- | --- |
| `학번을 작성해 봅니다.` | title | 식별 | 읽기만 (실명이 있으면 중지) |
| `나의 생각` | text | 학생 원문 | **읽기만 · 절대 수정 금지** |
| `기사 제목을 찾아 봅니다.` | relation | 원본 | 읽기만 |
| `내 이름을 찾아 봅시다.` | relation | 개인정보 | 읽기만 · 화면 공유 시 노출 금지 |
| `AI 이해` / `AI 연결` / `AI 표현` | number 0~5 | AI 초안 | 승인 후 쓰기 |
| `피드백` | text | AI 초안 | 승인 후 쓰기 |
| `평가 포워드` | text | AI 초안 | 승인 후 쓰기 |
| `분석 상태` | select | AI 초안 | 승인 후 쓰기 (대기/분석 중/완료/오류) |
| `평가 버전` / `평가일` | text / date | AI 초안 | 승인 후 쓰기 |
| `교사 우선 검토` | checkbox | AI 초안 | 경계 판단이 있으면 체크 제안 |
| `교사 이해` / `교사 연결` / `교사 표현` | number 0~5 | 교사 확정 | 교사가 불러 준 값만 |
| `교사 총점` | number | 교사 확정 | 교사가 불러 준 값만 |
| `교사의 피드백` | text | 교사 확정 | 교사가 불러 준 값만 |
| `AI-교사 차이 사유` | text | 교사 확정 | 교사가 승인한 문장만 |
| `교사 확인` | select | 교사 확정 | **자동으로 '완료'로 바꾸지 않음** |
| `세부특기사항` | text | 학생부 | **자동 저장 금지** · 채팅으로만 초안 제시 |
| `AI 총점` / `최종점수(교사반영)` / `수행평가 결과` | formula | 시스템 | **쓰기 불가** |

## B. 3F 과정중심평가 보드

| 필드 | 구분 | 권한 |
| --- | --- | --- |
| `Claude 평가 초안`, `강점`, `보완점`, `AI 이해/연결/표현`, `AI 확신도`, `분석 상태` | AI 초안 | 승인 후 쓰기 |
| `교사 판단`, `교사 총점`, `피드백`, `평가 포워드`, `AI-교사 차이 사유` | 교사 확정 | 교사가 불러 준 값만 |
| `교사 확인`, `기록 준비 상태`, `학생기록 초안`, `기록 근거 맵` | 교사 확정 | 자동 확정 금지 |
| `3F 진행 상태` | 진행 | 교사가 단계를 말할 때만 이동 |
| `댓글`(학생 원문), 학생·기사·원본 제출 relation, `성공 기준`, `성취기준` | 원본 | 읽기만 |
| `AI 총점`, `교사 총점 1` | formula | 쓰기 불가 |

`3F 진행 상태`는 1 피드업 → 2 근거 수집 → 3 AI 초안 → 4 교사 검토 → 5 피드백 →
6 피드포워드 → 7 후속 확인 → 8 기록 준비 → 완료 순서로만 이동한다. 단계를
건너뛰지 않는다.

## 저장 전 자기 점검

- [ ] 학생 원문·relation·수식 필드를 대상에서 제외했는가
- [ ] 교사 확정 필드에 AI가 만든 문장을 넣지 않았는가
- [ ] `교사 확인`을 자동으로 완료로 바꾸지 않았는가
- [ ] `세부특기사항`을 저장 대상에서 뺐는가
- [ ] 현재값 → 새값 표를 교사에게 보여 주었는가
- [ ] 교사의 명시적 승인 문장을 받았는가
