# 연수 후 심화 숙제 — Claude 자동평가 엔진 전환

이 과제는 본 수업의 수료 필수 과제가 아니다. 초보자는 설계형으로 제출할 수 있고, 실제 코드 전환은 선택 심화다.

## 1. 목적

`노션×Claude로 완성하는 NIE 과정중심평가 대시보드` 연수의 명칭과 실제 시연을 일치시키기 위해, 현재 OpenAI API로 생성하는 성취기준별 평가 초안을 Claude API 경로로 전환한다.

Notion 페이지 수집, 루브릭 연결, 교사 최종평가 저장과 학급 리포트는 유지한다. 변경 대상은 평가 초안을 생성하는 모델 경로와 그 사실을 화면·기록에 정확히 표시하는 부분이다.

## 2. 기능 요구사항

- Notion에서 가져온 학생 결과물과 연결된 루브릭을 Claude에 전달한다.
- Claude는 성취기준마다 점수, 근거, 피드백, 향상 행동, 제안 이유, 완료 확인 기준과 재작성 질문을 구조화해 반환한다.
- 학생 원문에 없는 판단은 만들지 않고 근거 부족 또는 교사 확인 필요로 표시한다.
- Claude 초안은 `ai-draft` 출처로 저장하고 교사 최종평가와 분리한다.
- 평가 카드와 대조 화면에 실제 Claude 모델명을 표시한다.
- Claude 호출 실패 시 OpenAI로 조용히 대체하지 않는다. 교사가 이해할 수 있는 오류와 재시도 방법을 보여준다.

## 3. 범위 밖

- Notion 템플릿 자동 생성
- 교사별 개인 Notion OAuth
- Google Sheets, 이미지·PDF·Word 입력
- 학생부 기록 자동 확정
- 교사 검토 없는 자동 피드백 전송

## 4. 구현 단계

### 1단계. 현재 평가 생성 경로 조사

- OpenAI 호출 위치와 평가 프롬프트 확인
- 구조화 응답 스키마와 기존 평가 데이터 호환성 확인
- 모델명 저장과 오류 처리 위치 확인

완료 조건: 변경 대상 파일, 함수, 환경변수와 회귀 위험 목록이 정리된다.

### 2단계. Claude 제공자 경로 구현

- 서버 전용 Claude API 키와 모델 환경변수 추가
- 기존 평가 스키마를 만족하는 Claude 구조화 응답 처리
- 향상 방법과 재작성 질문의 누락·형식 오류 검증
- 긴 Notion 결과물의 길이 제한과 오류 안내 처리

완료 조건: 합성 NIE 결과물로 Claude 초안이 생성되고 교사 평가를 덮어쓰지 않는다.

### 3단계. 화면과 운영 문구 정합화

- 평가 실행 영역에 `Claude 평가 초안` 표시
- 평가 카드와 대조 화면에 Claude 모델명 표시
- Claude가 읽지 못한 블록과 근거 부족 판단을 교사 확인 필요로 표시
- 배포 체크리스트와 개인정보 안내 갱신

완료 조건: 참가자가 화면만 보고 Claude 초안과 교사 최종평가를 구분할 수 있다.

### 4단계. 연수 리허설 검증

- 합성 골든 케이스 v1 전체 평가
- Claude 근거와 학생 원문 대조
- 교사 수정·최종평가 저장
- 향상 행동을 적용한 v2 연결과 변화 비교
- Claude 장애 시 수동 프롬프트 대체 흐름 확인

완료 조건: 참가자 권한의 테스트 계정으로 3차시 핵심 흐름을 처음부터 끝까지 완주한다.

## 5. 수용 기준

- [ ] 자동평가 요청이 실제 Claude API로 전달된다.
- [ ] 저장된 초안의 모델명으로 Claude 사용을 확인할 수 있다.
- [ ] Claude 초안과 교사 최종평가가 별도 저장된다.
- [ ] 모든 기준별 판단에 학생 원문 근거 또는 근거 부족 표시가 있다.
- [ ] 향상 행동, 이유, 완료 확인 기준과 재작성 질문이 구조화되어 표시된다.
- [ ] Claude 실패 시 OpenAI로 자동 대체되지 않는다.
- [ ] 실제 학생정보 없이 합성 골든 케이스 리허설을 통과한다.
- [ ] 실제 사례 사용 전 익명화·기관 지침·공개 범위 확인 절차가 있다.

## 6. 숙제 제출 방식

### A. 구현형

- Claude 제공자 경로를 구현한 브랜치 또는 PR
- 실제 Claude 모델명이 보이는 실행 화면 또는 평가 기록
- API 키 누락·호출 실패 등 오류 경로 확인 자료
- 구현 중 판단과 남은 위험을 정리한 5줄 성찰

### B. 설계형

- 현재 OpenAI 경로와 Claude 전환 후 경로를 비교한 흐름도
- 변경할 파일·함수·환경변수 목록
- 이 문서의 수용 기준을 사용한 점검표
- 구현한다면 먼저 검증할 항목을 정리한 5줄 성찰

두 유형 모두 실제 학생정보 대신 합성 골든 케이스를 사용하고, OpenAI 결과를 Claude 결과로 잘못 표시하지 않아야 한다.
