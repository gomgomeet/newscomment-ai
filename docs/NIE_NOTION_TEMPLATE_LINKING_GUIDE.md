# NIE Notion 복제 템플릿과 Claude 평가보드 연결 안내

이번 연수에서는 평가보드가 Notion 페이지를 자동으로 만드는 기능을 사용하지 않는다. 강사가 제공한 **NIE 신문평가 기본 템플릿을 공동 연수용 Notion 워크스페이스 안에 복제한 뒤**, 학생 결과물 페이지 링크를 Claude 평가보드에 연결한다.

자동 생성은 후속 개발 범위로 남긴다. 현재 목표는 참가자가 템플릿 구조를 이해하고, 한 학생의 결과물을 원자료 확인부터 교사 최종평가까지 직접 연결하는 것이다.

연수 전체 흐름과 차시별 강사 멘트는 [노션×Claude NIE 과정중심평가 대시보드 연수 운영 교안](NOTION_CLAUDE_NIE_EVALUATION_TRAINING_RUNBOOK.md)을 따른다.

현재 웹 평가보드의 평가 생성 엔진은 OpenAI API다. 이번 본 수업에서는 평가보드로 Notion 원문을 수집하고, 익명화한 원문과 루브릭을 Claude에 직접 제공해 평가 초안을 받은 뒤 교사 확인 결과를 보드에 기록한다. Claude API 경로 전환은 연수 후 심화 숙제이며 본 수업의 선행 조건이 아니다.

현재 평가보드는 서버에 설정된 하나의 `NOTION_API_KEY`를 사용한다. 따라서 그 통합이 연결된 워크스페이스의 페이지만 읽을 수 있다. 참가자마다 서로 다른 개인 워크스페이스에 복제하는 방식은 현재 공용 평가보드에서는 지원하지 않는다.

## 1. 역할 분담

- Notion: 기사 읽기, 근거 기록, 의견 작성, 수정본, 성찰이 남는 학생 활동 공간
- Claude: 학생 원문에서 성취기준별 근거, 강점, 보완점과 향상 행동의 초안을 만드는 도구
- 평가보드: 원자료 수집, Claude 분석 초안, 교사 점수·근거·피드백, 학급 리포트를 관리하는 공간
- NIE 기본 템플릿: 두 공간이 같은 평가 언어를 사용하도록 돕는 표준 입력 양식

교사 최종평가와 Claude 초안은 평가보드의 Supabase에 분리 저장한다. 학생 Notion 페이지에는 학생의 활동 과정과 결과물을 남긴다.

## 2. 템플릿에 유지할 필수 항목

템플릿을 교과에 맞게 수정해도 다음 항목은 유지한다.

1. 기사 제목, 언론사, 날짜, 원문 링크
2. 기사 핵심 내용
3. 주요 쟁점
4. 기사에서 찾은 근거 문장
5. 사실과 의견 구분
6. 학생의 주장과 이유
7. 다른 관점 또는 예상 반론
8. 더 알아볼 질문
9. 처음 작성한 의견
10. 피드백을 반영한 수정 의견
11. 무엇을 어떻게 수정했는지에 대한 성찰
12. AI 활용 여부와 학생의 확인 과정

이 항목들은 기사 이해, 근거 활용, 비판적 읽기, 생각 표현, 수정·성찰을 성취기준별로 확인하기 위한 최소 구조다.

## 3. 강사 사전 준비

1. 강사 계정에 공동 연수용 Notion 워크스페이스 또는 연수 전용 상위 페이지를 준비한다.
2. 참가자를 해당 워크스페이스나 상위 페이지의 편집 가능한 게스트로 초대한다.
3. 원본 NIE 템플릿을 연수용 상위 페이지 아래에 준비한다.
4. 참가자가 같은 연수용 워크스페이스 안에 사본을 만들 수 있도록 복제 링크와 복제 위치를 안내한다.
5. 템플릿에는 실제 학생 정보가 아닌 샘플 기사와 가상 학생 자료만 넣는다.
6. 평가보드 서버에 공동 워크스페이스용 `NOTION_API_KEY`를 설정한다.
7. Notion 통합은 연수용 상위 페이지에만 연결하고 개인 문서가 있는 상위 영역에는 연결하지 않는다.
8. 선택 사항으로 `NIE_NOTION_TEMPLATE_URL`에 복제 링크를 설정한다. 값이 있으면 평가보드에 `NIE 템플릿 복제하기` 버튼이 나타난다.
9. 수업활동과 NIE 성취기준 루브릭을 미리 만든다.
10. 연수 전에 참가자와 같은 권한의 테스트 계정으로 공동 연수용 상위 페이지 안에 사본을 만들 수 있는지 확인한다.

템플릿 복제 링크는 공개되어도 되는 연수용 링크만 사용한다. Notion API 토큰이나 비공개 페이지 URL을 복제 링크로 넣지 않는다.

참가자가 게스트 권한으로 공동 공간에 직접 복제할 수 없다면 연수 직전에 강사가 `참가자-01-v1` 형식의 사본을 인원수만큼 만들어 배정한다. 이 대체 절차도 자동 생성 기능이 아니라 강사가 원본 템플릿을 수동 복제해 제공하는 현재 운영 방식에 포함한다.

### 개인 워크스페이스에서 사용하려는 경우

현재 가능한 방법은 교사가 평가보드를 별도로 실행하고 자기 워크스페이스에서 만든 `NOTION_API_KEY`를 서버 환경변수에 설정하는 것이다. 공용 평가보드 화면에 개인 Notion 토큰을 입력하거나 URL에 토큰을 붙여서는 안 된다.

교사별 개인 워크스페이스를 하나의 공용 평가보드에 안전하게 연결하는 기능은 후속 개발 범위다. 교사별 토큰 암호화 저장 또는 Notion OAuth, 연결 해제, 권한 범위 표시가 먼저 필요하다.

## 4. 참가자 실습 순서

### 1단계. 템플릿 복제

1. 평가보드의 `NIE 템플릿 복제하기` 또는 강사가 제공한 링크를 연다.
2. Notion의 `복제`를 누르고 복제 위치를 **강사가 지정한 공동 연수용 워크스페이스 또는 상위 페이지**로 선택한다.
3. 개인 메모가 있는 자기 워크스페이스로 복제하지 않는다. 현재 공용 평가보드의 통합은 그 페이지를 읽을 수 없다.
4. 페이지 이름을 `학급-번호-활동명-v1`처럼 바꾼다. 실명 대신 학생 번호나 별칭을 권장한다.

### 2단계. 학생 결과물 작성

1. 샘플 기사의 제목과 원문 링크를 입력한다.
2. 핵심 내용, 근거 문장, 주장과 이유를 작성한다.
3. 처음 의견과 수정 의견을 덮어쓰지 않고 각각 남긴다.
4. 마지막에 수정 내용과 AI 활용 여부를 성찰한다.

### 3단계. 평가 앱 통합 연결

1. 복제한 학생 결과물 페이지를 연다.
2. 오른쪽 위 `공유` 또는 `...` 메뉴에서 `연결`을 선택한다.
3. 평가보드가 사용하는 Notion 통합을 추가한다.
4. 상위 개인 페이지 전체가 아니라 평가할 수업 페이지에만 연결한다.

### 4단계. 평가보드에 연결

1. Notion에서 학생 결과물 페이지 링크를 복사한다.
2. 평가보드에서 해당 수업활동을 연다.
3. `복제한 Notion 템플릿 연결` 카드에 학생 식별명과 페이지 링크를 입력한다.
4. `가져온 뒤 AI 평가 초안 바로 생성`은 선택하지 않고 원문만 수집한다.
5. `페이지 읽고 평가하기`를 실행해 원본 링크와 수집된 내용을 확인한다.

### 5단계. 교사 확인과 확정

1. `원본 Notion 페이지 열기`로 학생 원문을 확인한다.
2. 이미지, PDF, 임베드처럼 자동으로 읽지 못한 자료를 따로 확인한다.
3. 익명화한 원문과 루브릭을 운영 교안의 프롬프트로 Claude에 제공한다.
4. Claude의 기준별 점수, 근거, 향상 방법과 완료 확인 기준을 성취기준·학생 원문과 대조한다.
5. 타당한 내용만 학생 수준에 맞게 수정하고 교사 최종평가로 저장한다.

## 5. 수정본을 다루는 현재 방법

현재 평가보드는 동일한 Notion 페이지를 중복 수집하지 않는다. 학생이 같은 페이지를 수정해도 이미 가져온 평가자료가 자동 갱신되지 않는다.

연수에서는 수정 전후 증거를 보존하기 위해 다음 방법을 사용한다.

1. 최초 제출 페이지를 `...-v1`로 유지한다.
2. 학생이 v1을 복제해 `...-v2` 수정본을 만든다.
3. 수정본 상단에 v1 원문 링크와 `수정한 점`을 기록한다.
4. v2 페이지를 평가보드에 새 결과물로 연결한다.
5. 교사는 v1과 v2의 성취기준별 변화를 비교한다.

같은 페이지를 덮어쓰는 방식은 과정의 증거가 사라지므로 이번 연수에서는 사용하지 않는다. 페이지 버전 자동 수집과 수정 전후 대조는 후속 개발 범위다.

## 6. 실습 성공 기준

- [ ] 참가자가 제공된 NIE 템플릿을 지정된 공동 연수용 위치에 복제했다.
- [ ] 학생 실명 대신 번호 또는 별칭을 사용했다.
- [ ] 복제한 학생 페이지에 평가 앱 통합을 연결했다.
- [ ] 평가보드에 학생 식별명과 페이지 링크를 입력했다.
- [ ] 원본 페이지 링크와 Claude 초안이 평가 카드에 표시됐다.
- [ ] 자동으로 읽지 못한 자료를 교사가 직접 확인했다.
- [ ] Claude 초안과 교사 최종평가가 분리되어 저장됐다.
- [ ] 향상 방법과 재작성 질문을 교사가 검토했다.
- [ ] 수정본은 v2 페이지로 복제해 v1과 함께 보존했다.

## 7. 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 템플릿 복제 버튼이 없다 | 강사가 별도로 제공한 링크를 사용하거나 `NIE_NOTION_TEMPLATE_URL` 설정을 확인한다. |
| 공동 연수용 위치를 복제 대상으로 선택할 수 없다 | 참가자의 편집 권한을 확인한다. 게스트 권한으로 해결되지 않으면 강사가 참가자별 사본을 미리 만들어 배정한다. |
| 개인 워크스페이스에 복제한 페이지를 읽지 못한다 | 현재 공용 보드는 공동 연수용 워크스페이스의 통합만 사용한다. 지정된 연수용 위치에 다시 복제한다. |
| 페이지를 읽을 수 없다 | 해당 학생 페이지의 `공유 → 연결`에 평가 앱 통합을 추가했는지 확인한다. |
| 이미 가져온 페이지라고 나온다 | 기존 평가자료를 사용한다. 수정본이면 페이지를 v2로 복제해 새 링크를 연결한다. |
| 이미지·PDF가 평가되지 않는다 | 현재는 첨부 위치만 표시한다. 교사가 원본에서 직접 확인한다. |
| 페이지 일부만 반영됐다고 나온다 | 길이 제한 또는 블록 수 제한이다. 원본 페이지를 열어 누락 부분을 확인한다. |

## 8. 후속 개발: Notion 템플릿 자동 생성

자동 생성은 이번 연수 이후 다음 순서로 검토한다.

1. 평가보드에 `NIE 템플릿 만들기` 기능 추가
2. 교사별 Notion OAuth 또는 개인 토큰 암호화 저장과 연결 해제
3. 교사 워크스페이스와 Notion 쓰기 권한 확인
4. 필수 활동 블록과 템플릿 버전 자동 생성
5. 생성된 페이지를 수업활동과 루브릭에 자동 연결
6. 학생별 페이지 일괄 생성과 별칭 적용
7. v1·v2 수정본 연결과 성취기준별 변화 비교

자동 생성 기능이 들어가더라도 기본 원칙은 같다. Notion은 학생 활동 공간으로 사용하고, Claude 초안과 교사 최종평가는 평가보드에 분리 저장한다.
