# 질문 챗봇 평가 재설계 — 진단과 계획

2026-08-26 첫 실수업(단샘초 4-1, 22명) 결과를 읽고 다시 세운 설계다.
아직 구현 전이며, 결정된 것과 남은 것을 구분해 적는다.

## 1. 무엇이 잘못됐나 — 실제 데이터

### 총점이 항목 합과 다르다 (22명 중 14명)

| 번호 | 총점 | 항목 합 | 차이 |
| --- | --- | --- | --- |
| 2 | 11 | 3 | +8 |
| 13 | 10 | 3 | +7 |
| 20 | 0 | 7 | −7 |
| 14·17·7 | 9 | 3 | +6 |

**원인** — 노션 칸 이름과 코드가 찾는 이름이 다르다.
`lib/notion/questioning-chatbot.ts`의 `findPropertyKey`는 정확히 같거나
칸 이름이 후보를 통째로 포함해야 찾는다.

```
"근거 확인".includes("자료 근거 확인")     → false ✖
"[유형확장]".includes("질문 유형 확장")    → false ✖
"성찰질문".includes("질문 다시 쓰기·성찰") → false ✖
"성취기준·자료 연결" === 후보              → true ✅
```

챗봇이 실제로 채우는 칸은 `성취기준·자료 연결`과 `총점` 둘뿐이다.
그런데 총점은 **내부 네 항목을 전부 더한 값**(`totalScore`)이라 어긋난다.
나머지 셋은 **조용히 건너뛴다** — 그래서 오늘까지 아무도 몰랐다.

### 일어나지 않은 일을 채점했다

`성찰질문` 칸이 대부분 비었다. 아이들이 성찰을 못 한 게 아니라
**챗봇이 성찰을 물어본 적이 없다.** 학생이 묻고 챗봇이 답하는 것만
끝없이 반복되다 끝났다.

### 성취기준을 보지 못한다

오늘 성취기준은 `[4국02-03] 질문을 활용하여 글을 예측하며 읽고
자신의 읽기 과정을 점검한다`였다.

- **4-1-11번**은 `아하 난 이 그린피스가 세계 나라를 말하는 줄 알았어`라며
  **자기 오해를 스스로 알아차렸다**. 성취기준의 핵심 행동인 `읽기 과정 점검`을
  정확히 수행했다. **총점 0점.**
- **4-1-13번**은 낱말 뜻만 넷 물었다. 오늘 성취기준의 표적이 아니다. **총점 10점.**

`buildStandardAssessmentAnalysis`가 성취기준에서 표적 행동을 뽑고는 있지만,
그것이 4항목으로 이어지지 않아 **버려진다**. 항목 이름과 초점은 성취기준과
무관하게 늘 고정이다.

## 2. 평가 요소 — 네 항목

평가가 챗봇의 행동에서 자동으로 나오게 한다. **챗봇이 물어야 점수가 생긴다.**

| | 항목 | 무엇을 보나 |
| --- | --- | --- |
| ① | **질문하기** | 스스로 질문을 만들어 냈는가 — 행위 자체 |
| ② | **지문 이해** | 지문 내용을 이해하고 있는가 |
| ③ | **성취기준** | 교사가 강조한 표적에 닿았는가 |
| ④ | **성찰질문과 의견 표현** | 이 글에 대한 자기 생각을 말했는가 |

**①은 행위, ②③은 내용, ④는 표현**이다. ②③은 두 국면 모두에서 증거가 나온다.

### 증거가 어디서 나오나

| 항목 | 1국면 (학생이 묻는다) | 2국면 (챗봇이 묻는다) |
| --- | --- | --- |
| ① 질문하기 | 질문의 수와 스스로 만든 정도 | — |
| ② 지문 이해 | 지문 안을 겨냥한 질문의 내용 | 이해 확인 질문에 대한 답 |
| ③ 성취기준 | 표적 신호가 든 질문의 빈도 | 성취기준 질문에 대한 답 |
| ④ 성찰·의견 | (드물게) 스스로 표현한 생각 | 마지막 질문에 대한 답 |

**①은 1국면에만 있다.** 챗봇이 물어 준 것에 답한 건 질문하기가 아니다.
B2로 넘어간 아이는 ①이 낮지만 ②③④는 받는다. **0점으로 끝나지 않는다.**

### 참고 — 질문에 점수를 매길 때의 경고

질문 형성 연구에서 반복되는 지적이 있다. 루브릭이 질문의 **질**을 재면
"충분히 좋은 질문이 아닐까 봐" 아예 묻지 않는 아이가 생긴다. 메타인지적·행동적
기대에 초점을 두는 편이 낫다. 위 네 항목은 모두 **행동 증거**이며 질문의
좋고 나쁨을 재지 않는다.

## 3. 대화 국면 설계

```
1국면 · 학생이 묻는다
   │
   ├─ 지문 관련 질문 4개 ─────────────→ 2국면 (갈래 A)
   │
   └─ 3~4턴 지났는데 지문 관련 1개 이하
         ↓
      B1  "혹시 지문에서 모르는 단어나 이해하기 어려운 문장이 있나요?"
         ├─ 낱말·문장을 댐 → 답해 주고 ↺ 1국면 복귀
         └─ 없어요 / 무응답
               ↓
            B2  "혹시 글에 대해서 질문하기가 어려우면 제가 질문해도 될까요?
                 제 질문에 대한 답을 지문에서 찾아보세요."  → 2국면
```

**지문 관련 질문이란** — 지문의 낱말·문장·내용을 겨냥한 질문.
딴소리·이름·대필 요청은 세지 않는다.

**갈래 A에 도달한 아이는 `자료 내용 이해`가 달성된 것으로 본다.**
4~5개를 스스로 물었다는 것 자체가 증거다.

**B1은 한 번만 쓴다.** 두 번 물으면 "너 못하지?"로 들린다.
턴을 뺏지 않으므로 3~4턴에 이르게 넣는다. 오늘 3~5턴에서 끝난 아이가 많아,
6턴까지 기다리면 써 보지도 못하고 수업이 끝난다.

### 챗봇이 묻는 3~5개

재료는 이미 있다 — 생각 카드(낱말·사실·추론)가 그 용도로 저장되고 있다.

| 순서 | 무엇 | 개수 |
| --- | --- | --- |
| 1 | 지문 이해 확인 | 1~2 |
| 2 | 성취기준 표적 | 1~2 |
| 3 | 생각과 느낌 | 1 (마지막, 반드시) |

### 난이도 적응

| 단계 | 무엇을 묻나 |
| --- | --- |
| 하 | 문장에 그대로 있는 것 |
| 중 | 사실 관계·비교 |
| 상 | 까닭·성취기준 표적 |

```
중에서 시작
  맞히면    → 상으로 올림
  못 맞히면 → 하로 내리고 볼 곳을 짚어 줌 ("둘째 문단을 다시 볼까요?")
  하에서도  → 답이 든 문장을 보여 주고 함께 읽음
  못 하면      "여기 이렇게 나와 있어요. 이 문장에서 찾을 수 있어요."
```

하에서도 막히는 아이에게는 **채점이 아니라 문답으로 지문을 읽어 주는 것**이다.

마지막 생각·느낌 질문은 난이도와 무관하다. 정답이 없으니 모든 아이가 답할 수 있고,
여기서 ④의 증거가 나온다.

## 3-1. 2국면에서 챗봇이 묻는 것 — 세 갈래

**재료는 이미 있다.** 생성형 AI가 만든 생각 카드가 그 용도로 저장되고 있다.

| 갈래 | 몇 개 | 어느 카드에서 | 예 |
| --- | --- | --- | --- |
| **ⓐ 지문 이해** | 1~2 | `vocabulary` · `fact` · `inference` | `조사에 몇 명이 참여했다고 나와 있어?` |
| **ⓑ 성취기준** | 1~2 | `expected_question` 중 표적에 맞는 것 + 성취기준에서 뽑은 표적 행동 | 성취기준이 `읽기 과정 점검`이면 → `읽으면서 처음 생각과 달라진 게 있었어?` |
| **ⓒ 생각과 의견** | 1 (마지막, 반드시) | `extension` 또는 고정 문형 | `이 글을 읽고 어떤 생각이 들었어? 네 생각이 궁금해.` |

**순서는 ⓐ → ⓑ → ⓒ**로 고정한다. 쉬운 것에서 시작해 자기 생각으로 닫는다.

**ⓒ는 난이도와 무관하다.** 정답이 없으니 어떤 아이든 답할 수 있고,
여기서 ④의 증거가 나온다. **ⓐ·ⓑ에서 아무리 막혀도 ⓒ는 반드시 묻는다.**

### 카드가 없거나 모자라면

생각 카드는 교사가 ⑧을 눌렀을 때 만들어진다. 없으면 지문에서 직접 만든다.

- ⓐ — 지문의 사실 문장 하나를 골라 그 안의 값을 묻는다
- ⓑ — 성취기준에서 뽑은 표적 행동을 그대로 질문으로 바꾼다
- ⓒ — 고정 문형을 쓴다

## 3-2. 지문을 넘어서는 추론 질문

오늘 4-1-3번이 `플라스틱은 우리 몸에 어떤 영향을 미칠까?`라고 물었다.
지문에 없다. 이런 질문을 어떻게 받을지가 설계의 갈림길이다.

### 원칙 — 위치를 나누되 벌하지 않는다

**지문 밖 질문은 나쁜 질문이 아니다.** 그렇게 다루면 아이가 상상을 멈춘다.
답할 수 없다는 것과 질문이 값지다는 것은 별개다.

그래서 **점수를 깎는 대신 어느 항목의 증거인지를 나눈다.**

| 항목 | 지문 밖 추론 질문이 증거가 되나 |
| --- | --- |
| ① 질문하기 | **된다.** 스스로 궁금해했다는 강한 증거다 |
| ② 지문 이해 | 안 된다. 글 내용이 아니다 |
| ③ 성취기준 | 성취기준이 `추론`·`적용`이면 **된다** |
| ④ 성찰·의견 | 생각을 담고 있으면 된다 |

### 응답 방식 — 세 걸음

```
1. 질문을 인정한다        "좋은 궁금증이에요."
2. 경계를 정직하게 말한다  "이 글은 거기까지는 말하지 않아요."
3. 두 갈래로 잇는다
   ├─ 더 알아볼 질문으로 남긴다
   │  "'더 알아볼 질문'으로 적어 둘게요."
   └─ 글에서 가장 가까운 대목으로 데려온다
      "대신 글에서 가까운 이야기는 여기예요. …"
```

**`더 알아볼 질문`은 그냥 하는 말이 아니라 실제로 기록에 남긴다.**
수업 뒤 교사가 그 목록을 보고 다음 차시를 열 수 있다. 아이에게는
"내 질문이 어디로 갔다"는 감각이 남는다.

### 실시간 리서치는 교사가 켠다

지금은 조건이 맞으면 웹에서 찾아 출처와 함께 답한다. 이건 **기본을 끄고
교사가 켜는 쪽**이 맞다.

- 켜면 — 답을 얻지만 수업이 지문 밖으로 흩어지고, 무료 키 한도에 걸린다
- 끄면 — 위 세 걸음으로 지문에 머문다

**차시 목표에 따라 다르다.** 지문 정독이 목표면 끄고, 탐구 확장이 목표면 켠다.
교사용 보드 ①~④ 패널에 `탐구 확장 — 자료 밖 질문도 찾아서 답하기` 스위치를 두었다.
수업 코드에 딸려 저장되므로 차시마다, 반마다 다르게 둘 수 있다.

### 지어낸 답을 막는 일곱 겹

자료 밖을 답하는 순간 지어낼 위험이 생긴다. 켤 수 있게 만든 이상 대책을 함께 둔다.

| | 대책 | 어디서 |
| --- | --- | --- |
| 1 | **검색 근거가 없으면 답하지 않는다** — 모델 기억이 아니라 `groundingChunks`에 실제로 잡힌 것만 쓴다 | `extractGroundedSources` |
| 2 | **출처 신뢰도 A·B만 통과** — C·D는 버리고 답을 포기한다 | `gradeSourceReliability` |
| 3 | **모르면 `모름`** — 검색이 뒷받침하지 않으면 한 낱말로 답하고, 그러면 답하지 않는다 | 지시문 |
| 4 | **숫자·날짜·이름·통계는 검색 결과에 적힌 것만** | 지시문 |
| 5 | **여러 출처의 사실을 섞어 새 주장을 만들지 않는다** | 지시문 |
| 6 | **출처끼리 어긋나면 고르지 말고 `모름`** | 지시문 |
| 7 | **근거가 한 곳뿐이면 단정하지 않는다** — `…라고 한 곳에서 설명해요. 더 확인해 보면 좋겠어요` | 답 생성 뒤 |

여기에 더해 **답에는 언제나 출처가 붙고**, `자료에는 직접 나오지 않지만`으로 시작해
**지문 안의 말이 아니라는 것이 아이에게 보이게** 한다. 리서치로 답한 내용은
카드로 저장되어 교사가 수업 뒤 확인할 수 있다.

**1·2번이 가장 강한 방어다.** 검색이 실제로 잡히지 않으면 아무 답도 나가지 않는다.
오늘 4-1-3번에게 나간 답에 `khms.or.kr`이 붙은 것은 이 관문을 통과했다는 뜻이다.

## 4. 패러프레이징 규칙

B1에서 아이가 "이 문장이 어려워요"라고 하면 쉬운 말로 바꿔 준다.
`지문에 없는 사실을 지어내지 않는다`와 한 끗 차이라 경계를 분명히 한다.

**원칙 — 바꾸는 것은 말이지 내용이 아니다.**

해도 되는 것
- 어려운 낱말 → 쉬운 낱말 (`잠식하고 있다` → `조금씩 차지하고 있다`)
- 긴 문장 → 두세 문장으로 쪼개기
- 한자어·피동 → 고유어·능동
- 까닭을 앞으로 빼서 읽기 쉽게

하면 안 되는 것
- **지문에 없는 예시·비유·배경 지식 덧붙이기** ← 가장 흔한 실패
- 요약해서 정보 빼먹기
- 판단 얹기 (`이건 나쁜 일이에요`)
- **숫자·주체·시점 바꾸기** (`137명`은 끝까지 `137명`)

세 걸음
1. 어디를 말하는지 짚는다 — `이 문장 말이지요? "…"`
2. 쉬운 말로 바꿔 말한다 — `이 문장은 이런 뜻이에요. …`
3. 한 번만 확인한다 — `또 이해가 되지 않는 부분이 있을까요?`

3번 문구를 이렇게 잡은 이유가 있다. `이제 어떤 말인지 보이나요?`는 이해를
시험하는 물음이라, 아직 모르는 아이가 **못 알아들었다고 고백해야** 한다.
`또 있을까요?`는 더 있는 것이 당연하다는 전제라 아이가 편하게 하나 더 댈 수 있고,
어려운 곳을 찾는 B1의 목적으로 자연스럽게 이어진다.

`쉽게 말하면`은 아이를 낮잡는 느낌이 있어 쓰지 않는다.

**낱말과 문장을 다르게 다룬다**

| 학생이 물은 것 | 어떻게 |
| --- | --- |
| 낱말 (`잠식이 뭐야?`) | 두 걸음 — 사전 뜻 먼저, 이어 물으면 문맥 뜻 |
| 문장 (`이 문장이 어려워요`) | 바로 패러프레이즈 |

문장에 어려운 낱말이 섞여 있으면 낱말 카드의 뜻을 **문장 안에 녹여 쓴다.**

**기계로 거를 수 있다**
- 숫자가 원문과 다르면 버린다
- 원문에 없던 고유명사가 나오면 버린다
- 내용어가 원문 + 낱말 카드를 크게 벗어나면 버린다

걸리면 패러프레이즈를 버리고 **원문을 그대로 인용한다.** 잘못 풀어 주는 것보다 낫다.

## 4-1. 평가 계획 — 무엇을 몇 점으로

### 배점

**네 항목 × 0~5점 = 20점.** 지금과 같은 총점이라 노션 칸을 바꾸지 않아도 된다.
**총점은 반드시 네 항목의 합**으로 계산한다(오늘 어긋난 원인).

### 항목별 판정 규칙

**① 질문하기** — 세는 방식

| 점수 | 기준 |
| --- | --- |
| 5 | 지문 관련 질문 5개 이상, 스스로 이어 감 |
| 4 | 4개 (갈래 A 도달) |
| 3 | 2~3개 |
| 2 | 1개 |
| 1 | B1 유도 뒤에 겨우 하나 |
| 0 | 끝까지 질문 없음 |

**지문 밖 추론 질문도 여기서는 센다.** 스스로 궁금해한 증거이기 때문이다.

**② 지문 이해** — 두 국면 합산

| 점수 | 기준 |
| --- | --- |
| 5 | 1국면에서 사실·관계를 묻고, 2국면 ⓐ에 근거를 들어 답함 |
| 4 | 2국면 ⓐ에 지문 근거로 답함 |
| 3 | 낱말·사실 질문이 있었고 ⓐ에 부분적으로 답함 |
| 2 | 낱말 질문만 있음 |
| 1 | 하 난이도까지 내려가 함께 읽고서야 답함 |
| 0 | 지문에 닿은 흔적 없음 |

**③ 성취기준** — 표적 신호의 빈도

| 점수 | 기준 |
| --- | --- |
| 5 | 1국면에 표적 질문이 둘 이상, 2국면 ⓑ에도 답함 |
| 4 | 표적 질문 하나 + ⓑ 응답 |
| 3 | ⓑ에 답함 (스스로 표적 질문은 없었음) |
| 2 | 표적에 스친 질문 하나 |
| 1 | ⓑ에 답을 시도했으나 근거 없음 |
| 0 | 표적과 닿은 것 없음 |

**표적 신호는 성취기준 + 챗봇 수업 메모에서 뽑는다.** 여기만 성취기준마다 달라진다.

**④ 성찰질문과 의견 표현** — 마지막 질문 ⓒ

| 점수 | 기준 |
| --- | --- |
| 5 | 자기 생각을 말하고 까닭이나 글의 내용과 이었음 |
| 4 | 자기 생각을 자기 말로 말함 |
| 3 | 짧게라도 생각이나 느낌을 말함 |
| 2 | `좋아요`처럼 한마디 |
| 1 | 물었으나 답하지 않음 |
| 0 | 묻지 못하고 대화가 끝남 |

**0점은 학생이 아니라 수업의 문제다.** ⓒ를 묻지 못했다는 뜻이므로,
0이 여럿이면 전환 시점을 앞당겨야 한다는 신호로 읽는다.

### 함께 저장할 것

지금은 점수와 근거 문장만 남는다. 여기에 셋을 더한다.

- **수준 이름** — `4점(우수)`처럼 서술어를 함께 저장해 교사가 기준을 볼 수 있게
- **도달 난이도** — 2국면에서 상·중·하 어디까지 갔는지
- **더 알아볼 질문** — 지문 밖 질문 목록

### 세특 피드백 규칙

- **주어는 학생이다.** `…설명했습니다`(챗봇 행동) ✖ → `학생은 …했다` ✅
- **챗봇 발화를 그 칸에 넣지 않는다.** 오늘 세 건이 그대로 들어갔다
- **하지 않은 것을 쓰지 않는다.** 근거는 실제 질문과 응답뿐

## 5. 구현 순서

| 단계 | 내용 | 크기 |
| --- | --- | --- |
| **1** | 노션 칸 이름 불일치 해소 — 박힌 문자열 대신 `config.rubric`을 순회해 각 라벨로 칸을 찾는다. 못 찾으면 **교사에게 알린다**(지금은 조용히 건너뜀) | 작음 |
| **2** | 패러프레이징 규칙 — Gemini 지시문 · 로컬 엔진 · 단일 HTML 프롬프트 세 곳 | 작음 |
| **3** | 국면 전환 — 지문 관련 질문 세기, 갈래 A / B1 / B2 | 중간 |
| **4** | 챗봇이 묻는 세 갈래(ⓐⓑⓒ) + 난이도 적응. 생각 카드에서 재료를 뽑는다 | 큼 |
| **5** | 평가 4항목(질문하기·지문 이해·성취기준·성찰과 의견)으로 교체, 채점 기준 서술어 함께 저장 | 중간 |
| **6** | 세특 피드백을 학생 주어로. 챗봇 발화가 그 칸에 들어가지 않게 차단 | 작음 |
| **7** | 지문 밖 추론 질문 — 세 걸음 응답 + `더 알아볼 질문` 기록 + 리서치 스위치 | 중간 |

**1·2·6은 국면 설계와 무관하게 지금 할 수 있다.** 오늘 겪은 문제의 절반이 여기서 사라진다.

## 6. 아직 정하지 않은 것

- **2국면에서 학생이 답하지 않고 딴 데로 가면** — 한 번 더 묻고 생각·느낌으로
  건너뛰는 쪽을 권한다. 그러면 어떤 아이든 마지막 질문은 받고 ④가 비지 않는다
- **패러프레이즈 예문이 4학년에게 맞는지** — 아이에게 나가는 말이라 교사 확인이 필요하다
