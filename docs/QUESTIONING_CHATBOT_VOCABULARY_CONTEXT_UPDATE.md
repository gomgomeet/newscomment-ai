# 질문 챗봇 어휘·문맥 질문 대응 설계

작성일: 2026-08-25

## 1. 관찰과 설계 문제

실제 학생 대화에서 가장 자주 나타나는 요구는 글의 주제나 제목을 곧바로 추론하는 질문보다 `이 단어가 무슨 뜻이에요?`와 같은 어휘 질문이었다. 기존 챗봇이 이를 일반 사실 질문이나 막힘으로 처리하면 사전처럼 정의만 말하거나, 반대로 학생에게 다시 찾아보라고 물어 기계적으로 느껴질 수 있다.

이번 변경은 어휘 질문을 부수적인 예외가 아니라 읽기 이해의 첫 관문으로 다룬다. 성취기준은 여전히 대화 전체의 나침반이지만, 현재 학생에게 필요한 도움이 낱말 이해라면 그 도움을 먼저 제공한다.

## 2. 전문적인 명칭

이 기능은 다음 개념을 결합한 **근거 기반 맥락화 어휘 지원**이라고 부를 수 있다.

- 어휘 의미 중의성 해소(Word Sense Disambiguation): 여러 사전 뜻 가운데 현재 문장에 맞는 뜻을 고른다.
- 문맥화 어휘 지도(Contextualized Vocabulary Instruction): 낱말을 고립된 정의가 아니라 실제 문장과 함께 이해한다.
- 근거 기반 응답(Grounded Response): 설명을 교사가 제공한 지문과 검토된 어휘 자료에 묶는다.
- 학생 바꿔 말하기 확인(Student Paraphrase Check): 학생이 자기 말로 다시 표현한 뜻을 짧게 확인해 이해를 안정시킨다.

이를 합성 학생과 여러 차례 대화하며 고친 과정은 **합성 학습자 기반 다중 턴 회귀평가**이자 **평가 주도 프롬프트·대화정책 최적화**다. LLM 가중치를 바꾸는 파인튜닝이나 실제 학생 학습 효과 검증은 아니다.

## 3. 교사형 응답 순서

낱말 뜻을 묻는 턴에서는 다음 순서를 기본으로 한다.

1. 사전적 의미: 학생 수준에 맞는 짧고 일반적인 뜻을 먼저 알려 준다.
2. 문장 근거: 그 낱말이 실제로 쓰인 지문 문장을 짧게 보여 준다.
3. 문맥적 의미: 앞뒤 문장, 수치, 대상, 행동을 근거로 이 글에서의 구체적인 뜻을 설명한다.
4. 학생 확인: 학생이 자기 말로 바꾸어 말하면 맞는 부분을 확인한다. 매번 새 문제로 시험하지 않는다.

예시는 다음과 같다.

```text
학생: 공회전이 뭐예요?
챗봇: ‘공회전’은 사전적으로 “차량이 움직이지 않는 상태에서 엔진만 돌아가는 일”이라는 뜻이에요. 이 글의 “아침에 공회전하는 차량 수도 27대에서 16대로 줄었다.”에서는 “등굣길에 자동차가 서 있는 동안 시동을 켜 둔 상황”이라는 뜻으로 쓰였어요.

학생: 차는 안 가는데 시동만 켜 둔 거죠?
챗봇: 네, 방금 네 말처럼 이해하면 돼요. 사전에 있는 넓은 뜻 가운데 이 글의 앞뒤 문장에 맞는 뜻을 골라 읽은 거예요.
```

## 4. 뜻을 가져오는 우선순위

답변 근거는 다음 순서로 선택한다.

1. 교사가 검토한 `material.vocabulary`
2. 지문 안의 직접 풀이 문장
3. 프로젝트가 검토해 둔 제한적 공통 어휘 목록
4. 위 근거가 없으면 뜻을 만들지 않고 사전 확인이 필요하다고 안내

`material.vocabulary`의 구조는 다음과 같다.

```ts
type MaterialVocabularyEntry = {
  term: string;
  dictionaryMeaning: string;
  contextualMeaning: string;
  contextSentence: string;
};
```

이미지 자료 분석에 LLM을 사용하는 경우에도 같은 구조로 최대 12개를 추출한다. `contextSentence`는 실제 자료 문장이어야 하며, `contextualMeaning`은 그 문장에서 선택되는 뜻이어야 한다. 분석 모델이 확신할 수 없는 뜻을 채우지 않도록 프롬프트와 출력 스키마에 명시했다.

## 5. 질문 분류의 주의점

어휘 질문은 `무슨 뜻`, `뜻이 뭐`, `뭔가요`, `어떤 말`과 같은 의도 표현과 물어보는 대상을 함께 확인한다. 단순히 `뜻`이라는 글자만 찾으면 다음 문장을 잘못 분류할 수 있다.

```text
청소가 소용없었다는 뜻이에요?
```

이 문장은 `소용없다`의 사전 뜻보다 문장 전체의 함의를 확인하는 질문에 가깝다. 따라서 구현은 따옴표 속 낱말, 조사 앞 명사구, `X이/가 뭐예요` 같은 형태를 먼저 찾고 문장 전체 해석 질문은 기존 이해·추론 경로에 남긴다.

## 6. 코드 반영

- `vocabulary` 질문 유형과 성취기준 연결을 추가했다.
- 자료 분석 결과에 `term`, `dictionaryMeaning`, `contextualMeaning`, `contextSentence`를 저장한다.
- 로컬 응답은 어휘 표, 지문 직접 풀이, 검토된 공통 어휘 순으로 근거를 찾는다.
- 외부 LLM 학생 대화 프롬프트에도 동일한 응답 순서와 비추측 원칙을 넣었다.
- 교사용 제작보드가 만드는 PRD, 기본 추가 지시, 일반 교사용 복사 프롬프트에 어휘 규칙을 포함했다.
- 학생이 뜻을 자기 말로 확인하거나 반대말·기사 숫자 이해로 이어 갈 때 정의를 기계적으로 반복하지 않게 했다.

생성 프로파일은 `30-session-dialogue-v2`로 올렸다. 이전 기본 지시만 사용하던 저장 설정은 새 기본값으로 이동하고, 교사가 직접 고친 지시는 덮어쓰지 않는다.

## 7. 합성 대화 보강

기존 개발 30회기에 어휘 중심 4회기 16턴을 추가했다.

| 회기 | 자료 | 핵심 어휘 | 확인한 흐름 |
|---|---|---|---|
| 31 | 급식 선택 배식 | 잔반, 선택 배식 | 일반 뜻과 학교 급식 맥락 구분 |
| 32 | 등굣길 공회전 | 공회전, 미세먼지 | 학생의 쉬운 바꿔 말하기 확인 |
| 33 | 급식실 소음 | 흡음판, 데시벨 | 단위 이해가 기사 수치 이해로 이어짐 |
| 34 | 축제 다회용 컵 | 다회용 | 일회용과의 대조로 의미 확장 |

전체 자동 회귀평가 결과는 다음과 같다.

```text
개발 세트: 34회기, 136턴
홀드아웃: 10회기, 40턴
전체: 44회기, 176턴
실패: 0건
검토 플래그: 0건
```

어휘 직접 질문에는 사전적 의미 표지와 지문·문맥 근거가 모두 있는지 추가 검사한다. 다만 자동 검사는 뜻의 교육적 적절성과 말투의 자연스러움을 완전히 판단하지 못하므로 교사 블라인드 검토가 여전히 필요하다.

## 8. 운영 권장안

- 교사는 학생이 어려워할 낱말 5~12개를 먼저 검토한다.
- 사전적 의미는 짧게 쓰고, 문맥적 의미는 지문의 대상과 행동이 드러나게 쓴다.
- 학생 질문 기록에서 자주 등장했지만 어휘 표에 없는 낱말을 개인정보 없이 집계한다.
- 새 낱말은 교사가 뜻과 근거 문장을 확인한 뒤 다음 버전의 어휘 표와 회귀평가에 추가한다.
- 같은 낱말이라도 지문이 바뀌면 `contextualMeaning`과 `contextSentence`를 다시 검토한다.
- 자동 통과만으로 배포하지 말고 실제 교사 말투와 학년 적합성을 표본 대화로 확인한다.

## 9. 남은 한계

- 오프라인 로컬 경로는 임의의 모든 낱말을 아는 전자사전이 아니다. 검토된 어휘 표와 지문 근거 밖의 뜻은 제한된다.
- 형태소 분석기 없이 질문 문장을 판별하므로 복잡한 오타, 은어, 긴 문장에서는 오분류가 남을 수 있다.
- 현재 4회기는 합성 시나리오다. 실제 학생이 자주 묻는 낱말 목록, 설명 길이, 이해 확인 방식은 교실 사용 자료로 다시 조정해야 한다.
- 사전 정의의 정확성과 학년 적합성은 교사의 최종 검토 대상이다.

## 8. 2026-08-25 어휘 지원 2차 보강 — 2단계 응답과 내장 기초 사전

### 바뀐 응답 순서 (교사 요청 반영)

기존에는 낱말 뜻을 물으면 사전적 뜻과 문맥적 뜻을 한 턴에 모두 말했다. 이제는 두 단계로 나눈다.

1. 학생이 낱말 뜻을 처음 물으면 **사전적 뜻만 짧게** 알려 주고 답을 마친다. 안내 문장은 붙이지 않는다(교사 확인 결과 매번 붙는 초대 문장은 불필요).
2. 학생이 "이 글에서는 무슨 뜻이에요?", "그 말은 이 기사에서 어떻게 쓰였어요?"처럼 이어서 물으면 **지문 문장을 근거로 문맥적 뜻**을 설명한다. 직전 답에서 다룬 낱말을 기억해 이어받는다.

```text
학생: 잔반이 뭐야?
챗봇: ‘잔반’은 사전적으로 “먹고 남긴 밥이나 음식”이라는 뜻을 말해요.
학생: 이 글에서는 무슨 뜻이에요?
챗봇: 이 글의 “남은 음식은 하루 평균 18kg에서 10.4kg으로 줄었다.”에서는 “학생들이 학교 급식에서 먹지 않고 남긴 음식”이라는 뜻으로 쓰였어요.
```

한 턴에 한 가지 교수 동작이라는 V2 대화정책과 맞고, 학생이 스스로 다음 질문을 만들게 한다. 첫 질문에 "여기서"가 섞여 있어도 사전 뜻부터 안내하며, 문맥 단계는 직전 턴에 사전 뜻을 준 경우에만 열린다.

### 함께 반영한 것

- **내장 기초 사전 103어 확장**: 급식·환경·탐구·읽기 학습(사실/의견/근거/요약/추론 등)·사회 시민·디지털 어휘. 파생어 매칭(`재활용품`→`재활용`, 잉여 2자 이하)과 조사·인용 어미 제거(`제트기라는`→`제트기`), 반말(`뭐야`)·짧은 되물음(`그럼 흡음판은요?`) 인식을 추가했다.
- **교사용 보드 낱말 등록 UI**: 자료 입력 3번 영역에 "낱말 뜻 알려 주기" 편집기를 추가했다. 낱말·사전적 뜻·이 글에서의 뜻·근거 문장을 등록하면 챗봇 응답에서 교사 등록 어휘가 내장 사전과 AI 분석보다 우선한다. Gemini 키 없이 텍스트만 입력하는 교사도 어휘 지원을 쓸 수 있다.
- **근거 없는 뜻 금지 유지**: 등록되지 않고 내장 사전에도 없는 낱말은 뜻을 지어내지 않고, 낱말이 쓰인 문장을 보여 주며 국어사전 확인을 안내한다.
- **회귀평가 확장**: 어휘 회기 4개(35~38)를 추가해 일반 어휘·학습 어휘·모르는 낱말·2단계 흐름을 고정했다. 평가 검사도 2단계 구조를 인지하도록 갱신했다. 최종 결과 **48회기 192턴, 실패 0건, 검토 플래그 0건** (lint·typecheck 통과).
