# 1차시 모듈 · 백워드 설계 기반 평가기준안 만들기

## 목표와 실행 경계

학생 결과물을 보기 전에 공식 성취기준에서 성공기준과 평가 증거를 도출하고, 교사 채점·학생 자기평가·Claude 평가 초안에 공통으로 사용할 평가기준안과 루브릭을 완성한다.

- 순서는 `성취기준 확인 → 바라는 이해·수행 명료화 → 수용 가능한 평가 증거 설계 → 평가기준안·루브릭 작성 → 교사 승인·버전 고정 → 수업 활동`이다.
- 공식 성취기준 코드와 원문은 교사가 제공한 것만 사용한다. 누락되면 제공을 요청하며 추정하지 않는다.
- 평가기준안 승인 전에는 학생 결과물을 열거나 채점하지 않는다.
- 학생 결과물을 본 뒤 평가 요소·성공기준·수준 경계를 바꾸지 않는다.
- AI 산출물은 `설계 초안`이며 교사가 승인한 버전만 평가에 사용한다.

## 필요한 입력

| 항목 | 확인할 내용 | 누락 시 처리 |
| --- | --- | --- |
| 활동 | 댓글쓰기, 의견 글, 발표, 보고서 등 | 신문기사 의견쓰기를 예시로 제안하되 교사에게 확인 |
| 학교급·학년 | 대상 학습자 | 초등 4학년 예시임을 표시 |
| 성취기준 | 공식 코드와 원문 | 제공 요청. 코드를 추정하지 않음 |
| 평가 과제 | 학생이 실제로 수행할 과제 | 과제 초안을 제안하고 승인 요청 |
| 평가 영역 | 관찰할 핵심 증거 | 기본 3개: 이해·연결·표현 |
| 수준 척도 | 4수준, 5수준, 0~5점 등 | 기본 4수준 |
| 활용 | 교사·학생·AI 중 사용 범위 | 세 용도 모두 구분해 작성 |

## 작성 절차

1. 성취기준의 핵심 지식·기능·태도를 분해한다.
2. 학생이 수업 후 보여 줄 `바라는 이해와 수행`을 관찰 가능한 문장으로 쓴다.
3. 수행을 확인할 수 있는 직접 증거를 정한다.
4. 증거를 묶어 3~5개 평가 요소로 만든다.
5. 각 요소의 최상 수준 성공기준을 먼저 쓰고, 질적으로 구분되는 하위 수준을 설계한다.
6. 교사용 루브릭, 학생용 자기평가, Claude가 찾을 증거 지시를 같은 기준에서 파생한다.
7. 교사 승인일과 버전을 기록하고 이후 평가 단계에서 잠근다.

## 필수 산출물

다음 일곱 블록을 순서대로 만든다.

1. **관련 성취기준**: 교사가 제공한 코드와 원문을 그대로 기록한다.
2. **평가 과제와 바라는 수행**: 무엇을 만들고 어떤 이해를 보여야 하는지 설명한다.
3. **교사용 루브릭**: 평가 영역 × 수준 표와 총점을 제시한다.
4. **영역별 해설**: 관찰 질문, 낮은·높은 수준 예시, Claude가 찾아야 할 증거, 증거 탐색 지시를 포함한다.
5. **학생용 자기평가 체크리스트**: 교사 언어와 분리해 `~했어요` 문장으로 쓴다.
6. **교사 모범 예시**: 입장이 다른 샘플 2개와 짧은 버전 1개, 예시 속 증거 표를 만든다.
7. **수업 활용과 승인 정보**: `입장이 아니라 근거를 평가한다`는 수업 발문, 승인자·승인일·버전을 기록한다.

## 기술문 품질 규칙

- 찬성·반대나 결론 자체가 아니라 자료와 생각의 연결, 근거의 질을 평가한다.
- `이해가 깊다` 대신 `기사의 핵심 내용을 자기 말로 언급한다`처럼 관찰 가능하게 쓴다.
- 수준 간 차이는 부사의 세기가 아니라 증거의 정확성·충분성·연결성·독립성 차이로 나타낸다.
- 한 결과물이 두 수준에 동시에 해당하지 않도록 수준 경계를 배타적으로 쓴다.
- 표현 영역은 기본적으로 `주장 → 이유 → 근거`를 확인한다.
- 짧다는 이유만으로 감점하지 않으며, 글에 없는 내용을 추정하지 않는다.
- 불확실하면 확신도를 낮추고 교사 검토를 요청한다.

## 척도 선택

- 기본 4수준: 영역당 1~4점, `매우 잘함 / 잘함 / 노력 필요 / 더 연습 필요`.
- 0~5점: 기사 이해·생각 연결·생각 표현 등 3영역 총 15점 체계와 맞출 때. 0점은 판단 근거 없음.
- 5수준: 논술·수행평가에서 맥락 파악, 교차 확인, 예상 반론, 실천 방안 등을 상위 기준으로 세분할 때.
- 7요소 확장형: 기사 이해·요약, 신뢰성·공정성, 주장, 근거, 조직·표현, 시민적 관점, 쓰기 윤리를 분리할 때.

## 출력 골격

```markdown
> 관련 성취기준
> `[교사가 제공한 코드]` 성취기준 원문

### 평가 과제와 바라는 수행
- 평가 과제:
- 바라는 이해:
- 수용 가능한 증거:

### (활동명) 평가 루브릭 — 총점 N점
| 평가 영역 | 4점 매우 잘함 | 3점 잘함 | 2점 노력 필요 | 1점 더 연습 필요 |
| --- | --- | --- | --- | --- |
| ① (영역) | … | … | … | … |

### ① (영역)
- 관찰 질문:
- 낮은 수준 예시 / 높은 수준 예시:
- Claude가 찾아야 할 증거:
- Claude 지시: "학생 글에서 …의 근거가 되는 표현을 찾아라."

### 학생용 자기평가 체크리스트
- [ ] …했어요.

### 교사 모범 예시와 증거
| 루브릭 영역 | 예시 속 증거 |

### 수업 활용과 승인
- 활용 발문:
- 승인자:
- 승인일:
- 루브릭 버전:
```

교사가 승인과 버전 고정을 명시하기 전에는 학생 결과물 평가로 넘어가지 않는다.
