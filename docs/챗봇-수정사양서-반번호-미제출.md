# 질문 도우미 챗봇 수정 사양서 v1.1 — 반·번호 전환 + 미제출 학생 찾기

> 사용법: 이 파일을 `question-bot` 폴더에 넣고 `claude` 실행 후
> **"이 사양서대로 index.html을 수정해 줘"** 라고 하면 됩니다.
> PRD v1.0의 나머지 조항(답 먼저 원칙, 4유형 분류, 저작권, 개인정보)은 그대로 유지합니다.

## 왜 바꾸나

| 기존 | 변경 | 이유 |
| --- | --- | --- |
| 모둠(1~6) · 번호(1~6) | **반(1~9) · 번호(1~35)** | 실제 학급은 모둠보다 반·번호로 관리합니다. 나이스·좌석표·평가 기록과 번호가 일치해야 교사가 바로 확인할 수 있습니다. |
| 보고서 = 참여한 학생만 표시 | **미제출(질문 없음) 학생 자동 표시** | 참여 명단만으로는 "누가 안 했는지"를 교사가 눈으로 세야 했습니다. |

개인정보 원칙은 그대로입니다 — **실명 입력란 없음**, 반·번호 + 선택 별명, 기기 밖 전송 없음.

## 1. 데이터 구조

```js
// localStorage 키
const LS_PROFILE = 'qb_profile';   // { cls, num, nick }
const LS_LOGS    = 'qb_logs';      // [{ cls, num, nick, q, type, ts }]
const LS_ROSTER  = 'qb_roster';    // { "3": 28, "4": 26 }  ← 반별 총 인원 (교사 입력)

const CLASS_MAX = 9;    // 반 수 (학교에 맞게 조정)
const NUM_MAX   = 35;   // 번호 최대

const sid   = p => `${p.cls}-${p.num}`;        // 저장·비교용 키
const label = p => `${p.cls}반 ${p.num}번`;    // 화면 표시용
```

### 기존 기록 이관 (한 번만 실행)

```js
function migrateLegacy(){
  try{
    const p = JSON.parse(localStorage.getItem(LS_PROFILE) || 'null');
    if (p && p.group != null && p.cls == null){        // 모둠 → 반
      localStorage.setItem(LS_PROFILE, JSON.stringify({cls:p.group, num:p.num, nick:p.nick||''}));
    }
    const logs = JSON.parse(localStorage.getItem(LS_LOGS) || '[]');
    let changed = false;
    logs.forEach(l => { if (l.group != null && l.cls == null){ l.cls = l.group; delete l.group; changed = true; } });
    if (changed) localStorage.setItem(LS_LOGS, JSON.stringify(logs));
  }catch(e){}
}
migrateLegacy();   // 스크립트 시작 부분에서 호출
```

## 2. 온보딩 화면 (첫 화면)

- 문구: "우리 반과 번호를 골라 주세요" (이름은 쓰지 않아요 🙂)
- **반**: `<select>` 1~9반 — 대부분 한 반만 쓰므로 마지막 선택을 기억해 기본값으로 둔다.
- **번호**: 1~35 버튼 그리드(태블릿 터치용, 최소 44px) 또는 `<select>`. 큰 글씨 유지.
- 별명: 선택 입력, 8자 이내.
- 상단 👋 버튼으로 사용자 변경(태블릿 공유) — 기존 기능 유지, 표시만 `3반 12번`으로.

```html
<div class="onboard">
  <h2>우리 반과 번호를 골라 주세요</h2>
  <p class="hint">이름은 쓰지 않아요. 선생님은 번호로만 확인해요.</p>
  <label>반
    <select id="obCls"></select>
  </label>
  <div class="numgrid" id="obNums"></div>
  <label>별명 (안 써도 돼요)
    <input id="obNick" maxlength="8" placeholder="예: 책벌레">
  </label>
  <button id="obStart" disabled>시작하기</button>
</div>
```

```js
const obCls = document.getElementById('obCls');
obCls.innerHTML = Array.from({length:CLASS_MAX},(_,i)=>`<option value="${i+1}">${i+1}반</option>`).join('');
obCls.value = localStorage.getItem('qb_last_cls') || '1';

let pickedNum = null;
document.getElementById('obNums').innerHTML =
  Array.from({length:NUM_MAX},(_,i)=>`<button type="button" class="numbtn" data-n="${i+1}">${i+1}</button>`).join('');
document.getElementById('obNums').onclick = e => {
  const b = e.target.closest('.numbtn'); if(!b) return;
  document.querySelectorAll('.numbtn').forEach(x=>x.classList.remove('on'));
  b.classList.add('on'); pickedNum = +b.dataset.n;
  document.getElementById('obStart').disabled = false;
};
document.getElementById('obStart').onclick = () => {
  const p = { cls:+obCls.value, num:pickedNum, nick:document.getElementById('obNick').value.trim() };
  localStorage.setItem(LS_PROFILE, JSON.stringify(p));
  localStorage.setItem('qb_last_cls', String(p.cls));   // 다음 학생 편의
  startChat(p);
};
```

- 질문 기록 시 `{cls, num}`을 함께 저장한다(기존 `group` 대신).
- 화면 어디서든 사용자 표시는 `label(p)` — 별명이 있으면 `3반 12번 · 책벌레`.

## 3. 보고서 — 미제출 학생 찾기

보고서 화면 **맨 위**에 학급 설정과 미제출 카드를 넣는다(교사가 가장 먼저 봐야 할 정보).

```html
<div class="rosterbar">
  <label>반 <select id="rpCls"></select></label>
  <label>우리 반 인원 <input id="rpTotal" type="number" min="1" max="40" step="1"></label>
  <button id="rpSave">적용</button>
  <span class="hint">인원을 넣으면 질문을 하지 않은 번호를 찾아 줍니다.</span>
</div>
<div id="rpMissing"></div>
```

```js
function getRoster(){ try{ return JSON.parse(localStorage.getItem(LS_ROSTER)||'{}'); }catch(e){ return {}; } }
function setRoster(cls, total){ const r=getRoster(); r[String(cls)] = total; localStorage.setItem(LS_ROSTER, JSON.stringify(r)); }

/** 해당 반에서 질문을 한 번도 하지 않은 번호 목록 */
function missingStudents(cls, total){
  const logs  = JSON.parse(localStorage.getItem(LS_LOGS)||'[]');
  const asked = new Set(logs.filter(l => +l.cls === +cls).map(l => +l.num));
  const miss  = [];
  for (let n = 1; n <= total; n++) if (!asked.has(n)) miss.push(n);
  return { miss, askedCount: asked.size };
}

function renderMissing(){
  const cls = +document.getElementById('rpCls').value;
  const total = getRoster()[String(cls)];
  const box = document.getElementById('rpMissing');
  if (!total){ box.innerHTML = `<p class="hint">인원을 입력하면 미제출 학생을 찾아 드려요.</p>`; return; }
  const { miss, askedCount } = missingStudents(cls, total);
  const rate = Math.round(askedCount / total * 100);
  box.innerHTML = `
    <div class="card ${miss.length ? 'warn' : 'ok'}">
      <b>${cls}반 참여 현황</b>
      <p>질문한 학생 <b>${askedCount}명</b> / 전체 <b>${total}명</b> (참여율 ${rate}%)</p>
      ${miss.length
        ? `<p>❗ 아직 질문하지 않은 학생 <b>${miss.length}명</b> — ${miss.map(n=>n+'번').join(', ')}</p>
           <button id="rpCopyMiss">미제출 번호 복사</button>`
        : `<p>🎉 모든 학생이 질문했어요!</p>`}
    </div>`;
  const btn = document.getElementById('rpCopyMiss');
  if (btn) btn.onclick = () => navigator.clipboard.writeText(
    `${cls}반 미제출 ${miss.length}명: ${miss.map(n=>n+'번').join(', ')}`);
}
```

- `rpCls` 옵션은 온보딩과 동일하게 채우고, 기본값은 기록에 가장 많이 등장한 반으로 둔다.
- `rpTotal`은 저장된 값으로 초기화하고, [적용] 시 `setRoster()` 후 `renderMissing()`.
- 기존 **"누가 질문했나요?"** 표의 라벨을 `3반 12번` 형식으로 바꾸고, 표 아래에 미제출 번호를 회색으로 함께 나열한다.
- **복사·인쇄 출력물에도 미제출 명단이 포함**되어야 한다(교사가 그대로 저장).
- 참여율은 격려용이며 성취 평가가 아님을 한 줄로 표시한다: "참여율은 질문 개수가 아니라 참여 여부만 봅니다."
