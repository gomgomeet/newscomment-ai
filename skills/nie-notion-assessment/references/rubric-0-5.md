# 승인된 루브릭 (3영역 × 0~5점 = 15점)

관련 성취기준 예시: `[4국02-04]` 글을 읽고 사실과 의견을 구분하며, 필자와 자신의 의견을 비교한다.

원칙: **입장이 아니라 근거를 평가한다.** 찬성/반대 자체는 점수에 영향을 주지 않는다.

## ① 기사 내용 이해

| 점수 | 기술문 |
| --- | --- |
| 0 | 판단 근거 없음 |
| 1 | 기사 언급이 없거나 내용을 크게 오해함 |
| 2 | 일부 사실만 언급하고 핵심과의 관련이 약함 |
| 3 | 기사의 핵심을 대체로 정확하게 언급함 |
| 4 | 핵심과 중요한 사실을 자기 말로 설명함 |
| 5 | 기사 속 서로 다른 입장과 배경까지 짚음 |

찾아야 할 증거: 기사 본문의 구체적 사실(수치·사건·발언) 활용 · 주장의 **주체** 구분
(기사 자체의 주장인지, 기사가 소개한 인물의 주장인지) · 내용 왜곡 여부.

지시 방식: "이해도 점수를 줘"가 아니라 **"학생 글에서 기사를 읽었다는 근거가 되는
표현을 찾아라"**.

## ② 기사와 자신의 생각 연결

| 점수 | 기술문 |
| --- | --- |
| 0 | 의견이라고 볼 내용이 없음 |
| 1 | 단순 감상이나 찬반 표시만 있음 |
| 2 | 까닭이 막연하거나 기사와의 연결이 약함 |
| 3 | 의견과 까닭을 기사에 연결함 |
| 4 | 경험·근거·예시로 뒷받침함 |
| 5 | 반대 입장이나 다른 가능성까지 고려함 |

경계 처리: 5수준 지표(반대 입장 고려)가 보이지만 3수준 요건(기사 연결)이 없으면
**상위 점수를 주지 말고 경계로 표시해 교사 판단을 요청한다.**

## ③ 자신의 생각 표현

| 점수 | 기술문 |
| --- | --- |
| 0 | 판단 근거 없음 |
| 1 | 뜻을 파악하기 어렵거나 주제와 무관함 |
| 2 | 설명이 짧거나 문장 연결이 불분명함 |
| 3 | 이해하기 쉽고 존중하는 언어로 씀 |
| 4 | 주장이 분명하고 흐름이 자연스러움 |
| 5 | 질문이나 대안으로 읽는 사람의 생각을 넓힘 |

기본 틀: **주장 → 이유 → 근거**.

## 채점 안전 규칙

- 글에 없는 내용을 추측하지 않는다.
- 짧다는 이유만으로 감점하지 않는다. 짧아도 근거가 있으면 근거로 평가한다.
- 맞춤법·오타는 ③ 표현에서만 고려하고 ①②에는 반영하지 않는다.
- 불확실하면 낮은 확신도를 표시하고 교사 검토를 요청한다.
- AI 점수는 초안이며 최종 판단은 교사가 한다.

## 학생용 자기평가 체크리스트 (채점 척도 아님)

- 나는 기사를 제대로 읽었나요? □ 기사의 중요한 내용을 넣었어요.
- 기사와 내 생각을 연결했나요? □ 기사 내용과 내 생각이 어떻게 연결되는지 썼어요.
- 내 생각을 잘 표현했나요? □ 무엇을 생각하는지 분명하게 썼어요. □ 왜 그렇게
  생각하는지도 썼어요. □ 기사 내용이나 나의 경험을 근거로 사용했어요.
