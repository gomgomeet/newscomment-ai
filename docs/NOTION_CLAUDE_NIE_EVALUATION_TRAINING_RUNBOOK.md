# 노션×Claude로 완성하는 NIE 과정중심평가

부제: 노션에 남은 학생 결과물을 근거 중심 평가, 피드백, 다음 학습으로 연결하기

이 문서는 Notion과 Claude를 처음 사용하는 교사를 위한 3차시 연수 운영 교안이다. 참가자는 준비된 익명 NIE 실제 사례 한 묶음을 세 차시 동안 계속 사용하며 다음 흐름을 완주한다.

**노션 v1 → 성취기준·성공 기준 → 직접 근거 → Claude 초안 → 교사 최종판단 → 노션 피드백 → 학생 v2 → 다음 수업**

## 1. 재설계 원칙

- 1차시는 Claude를 사용하지 않고 교사가 평가 기준과 직접 근거를 먼저 정한다.
- 2차시는 노션 원문을 필요한 만큼 복사해 Claude에 제공한다.
- 노션 페이지 연결, Notion 토큰, API 설정은 본 연수에서 사용하지 않는다.
- Claude 초안과 교사 최종판단을 분리해 노션에 직접 기록한다.
- 3차시는 교사가 학생의 답을 대신 쓰지 않고 피드백, v2 과제, 다음 수업 지원을 설계한다.
- 실제 익명 사례를 주 사례로, 합성 사례를 개인정보 설명과 장애 대응용으로 사용한다.

## 3. 도구와 사람의 역할

| 주체 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 노션 | v1, 성취기준, 직접 근거, 교사 피드백, v2 링크와 성찰을 보존 | 평가를 자동 확정하지 않음 |
| Claude | 제공된 원문에서 근거·강점·보완점·다음 행동의 초안을 작성 | 원문에 없는 사실 생성, 최종평가 확정 |
| 교사 | Claude 초안을 원문과 대조하고 최종판단과 피드백을 확정 | 검토하지 않은 AI 문장을 학생에게 전달 |
| 학생 | 피드백을 해석하고 자신의 결과물을 v2로 수정 | 교사나 Claude가 대신 쓴 답 제출 |

## 4. 연수에서 사용할 사례

### 주 사례: 준비된 익명 실제 사례

세 차시에서 같은 사례를 사용한다.

- v1 원문
- 성취기준 1개와 성공 기준 2~3개
- 교사 또는 동료 피드백
- 학생이 작성한 v2
- v1과 v2의 작성 시점

실제 사례는 연수 직전에 익명화, 기관 지침, 필요한 동의와 공개 범위를 다시 확인한다.

### 대체 사례: 합성 골든 케이스

[연수용 합성 골든 케이스 01](https://app.notion.com/p/3c9c5f01a4a481d9bfbfcc19054c5c15)은 개인정보 설명과 장애 대체 시연에만 사용한다. 실제 학생 사례라고 설명하거나 공식 평가·학생기록 근거로 사용하지 않는다.

## 5. 1차시 운영안

### 1차시｜노션 결과물에서 평가 근거 찾기

중심 질문: 무엇을 근거로 평가할까?

목표: 성취기준과 성공 기준을 먼저 정하고 노션 결과물에서 직접 근거를 찾아 Claude 입력 카드를 완성한다.

| 시간 | 강사 활동 | 참가자 활동 | 산출물 |
| --- | --- | --- | --- |
| 0~5분 | 세 차시 흐름과 중심 질문 안내 | 평가할 결과물 한 가지 기록 | 평가 대상 메모 |
| 5~12분 | 익명 실제 사례 v1 제시 | 원문에서 보이는 사실 두 가지 표시 | 첫 관찰 메모 |
| 12~20분 | 성취기준 범위 좁히기 시연 | 핵심 행동이 드러나는 성취기준 1개 선택 | 성취기준 1개 |
| 20~28분 | 관찰 가능한 성공 기준 시연 | 성공 기준 2~3개 작성 | 성공 기준 |
| 28~38분 | 직접 근거와 추론 비교 | 원문에 E01, E02 증거 ID 부여 | 증거 ID 목록 |
| 38~45분 | 증거와 기준 연결 시연 | 충분·일부·근거 없음·확인 불가 분류 | 증거–기준 연결표 |
| 45~50분 | Claude 입력 형식 정리 | 개인정보 제거 후 입력 카드 완성 | Claude 입력 카드 |

성공 기준:

- 성공 기준이 학생 결과물에서 관찰 가능한 말로 작성되었다.
- 직접 근거와 교사 추론을 구분했다.
- 근거 없음과 확인 불가를 억지로 점수화하지 않았다.
- Claude를 실행하기 전에 입력 카드를 완성했다.

## 6. 2차시 운영안

### 2차시｜Claude 평가 초안을 검토하고 교사 판단 정하기

중심 질문: Claude의 판단 중 무엇을 믿을 수 있을까?

목표: 1차시 입력 카드로 Claude 평가 초안을 만들고 각 판단을 원문과 대조해 교사 최종판단을 노션에 기록한다.

| 시간 | 강사 활동 | 참가자 활동 | 산출물 |
| --- | --- | --- | --- |
| 0~5분 | 입력 카드 필수 항목 확인 | 목표·기준·증거 ID·한계 점검 | 입력 준비 확인 |
| 5~10분 | 개인정보 제거 시연 | 실명·민감정보·원본 공유 링크 제거 | 비식별 입력본 |
| 10~18분 | Claude 프롬프트 구조 설명 | 입력 카드를 프롬프트에 배치 | 완성 프롬프트 |
| 18~28분 | Claude 실행과 출력 읽기 시연 | 성공 기준별 근거 초안 생성 | Claude 평가 초안 |
| 28~38분 | 판단 한 개 원문 대조 시연 | 확인됨·과장됨·근거 없음·확인 불가 표시 | 원문 대조표 |
| 38~45분 | AI 문장을 교사 언어로 수정 | 강점·보완점·근거를 최종판단으로 확정 | 교사 최종판단 |
| 45~50분 | 노션 분리 기록 시연 | Claude 초안·교사 판단·수정 이유 직접 기록 | 노션 평가 기록 |

본 차시에서는 노션 페이지 연결이나 토큰 설정을 하지 않는다. 참가자는 [Claude 평가 프롬프트｜원문 근거 확인용](https://app.notion.com/p/3c9c5f01a4a481fcae53f9c61eed69f7)을 사용해 복사·붙여넣기로 실습한다.

성공 기준:

- Claude 판단마다 연결된 원문 근거를 확인했다.
- 근거 없는 판단을 한 개 이상 삭제하거나 수정했다.
- Claude 초안과 교사 최종판단을 분리해 기록했다.
- 3차시에서 피드백으로 바꿀 우선 기준 1개를 정했다.

## 7. 3차시 운영안

### 3차시｜노션에 피드백을 기록하고 다음 학습 설계하기

중심 질문: 평가를 학생의 다음 행동으로 어떻게 바꿀까?

목표: 교사 최종판단을 실행 가능한 피드백으로 바꾸고 노션에 기록한 뒤 학생용 v2 과제와 다음 수업 지원을 설계한다.

| 시간 | 강사 활동 | 참가자 활동 | 산출물 |
| --- | --- | --- | --- |
| 0~8분 | 실제 사례 v1·피드백·v2 시연 | 실제 변화와 미변화 표시 | 변화 근거 |
| 8~16분 | 우선 보완점 선택 기준 설명 | 성공 기준 1개 선택 | 우선 기준 |
| 16~26분 | 모호한 조언과 실행 가능한 피드백 비교 | 수정 행동·이유·완료 기준 작성 | 향상 행동 카드 |
| 26~34분 | 답을 대신하지 않는 질문 시연 | 재작성 질문 1개 작성 | 재작성 질문 |
| 34~42분 | 노션 피드백·v2 안내 기록 시연 | 피드백·v2 과제·완료 기준 기록 | 노션 피드백 기록 |
| 42~48분 | 개별 피드백과 다음 수업 지원 구분 | 재설명·예시·면담·재작성 지원 선택 | 다음 수업 메모 |
| 48~50분 | 전체 평가 순환 정리 | 자기 수업의 첫 행동 기록 | 적용 선언 |

v2 운영 원칙:

- v1은 덮어쓰지 않고 보존한다.
- 교사는 학생의 v2 답을 대신 쓰지 않고 수정 과제와 성공 기준만 제공한다.
- 학생이 v2를 제출한 뒤에만 v1과 v2의 직접 근거를 비교한다.
- 실제 v2가 없으면 향상이나 성장을 확정하지 않는다.

## 8. 세 차시를 마치면 남는 한 묶음

- 익명화한 노션 결과물 v1
- 성취기준 1개와 성공 기준 2~3개
- 증거 ID가 붙은 직접 근거
- Claude 평가 초안
- 원문 대조가 끝난 교사 최종판단
- 수정 행동·제안 이유·완료 기준·재작성 질문
- 학생용 v2 과제와 v2 링크 자리
- 다음 수업 지원 메모

## 9. 초보자 지원 장치

- 한 번에 학생 한 명, 노션 결과물 한 개, 성취기준 한 개만 사용한다.
- 화면 용어를 원문·Claude 초안·교사 판단·다음 행동 네 가지로 제한한다.
- Claude가 작동하지 않으면 미리 준비한 결과 화면으로 원문 대조를 계속한다.
- 참가자에게 Notion 토큰이나 API 키를 입력하게 하지 않는다.
- 노션 연결보다 평가 근거 확인과 교사 판단에 시간을 사용한다.

## 10. 연수 전 강사 체크리스트

- [ ] 익명 실제 사례의 v1·피드백·v2 묶음 준비
- [ ] 공통 성취기준 1개와 성공 기준 2~3개 확정
- [ ] 참가자용 NIE 템플릿과 노션 평가 기록 영역 준비
- [ ] Claude 프롬프트와 결과 화면 점검
- [ ] 실제 사례 익명화·공개 범위·기관 지침 최종 확인
- [ ] 1차시 입력 카드부터 3차시 다음 수업 메모까지 전체 리허설

## 11. 연수 후 적용 과제

자기 수업의 익명 결과물 한 개에 같은 흐름을 적용한다.

1. 노션 v1과 성취기준·성공 기준을 준비한다.
2. Claude 평가 초안을 만들고 교사 최종판단을 기록한다.
3. 피드백과 v2 과제를 학생에게 제공한다.
4. v2 제출 후 변화 근거와 다음 수업 메모를 노션에 남긴다.

## 12. 최종 수료 기준

> 나는 노션 결과물에서 성취기준별 직접 근거를 찾고, Claude 초안을 원문과 대조해 교사 판단을 확정하며, 그 판단을 학생의 피드백·v2 과제·다음 수업 지원으로 연결할 수 있다.
