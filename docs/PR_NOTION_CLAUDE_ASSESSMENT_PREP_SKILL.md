# PR: 평가 준비 스킬의 연수 적용

## 요약

독립형 `notion-claude-assessment-prep` 스킬을 Codex와 Claude Code에서 사용할 수 있도록 제공하고, 이를 3차시 초보 교사 연수에 적용하는 운영안을 추가한다.

## 변경 내용

- `.agents/skills/notion-claude-assessment-prep/SKILL.md` 추가
- `.claude/skills/notion-claude-assessment-prep/SKILL.md` 추가
- 평가 준비, 결과 처리, 일괄 처리, 교사 검토 모드 정의
- Notion 자료 링크와 권한을 먼저 확인하는 입력 계약 추가
- 성취기준에서 문항·루브릭·폼·평가 DB 속성을 만드는 절차 추가
- 동일 활동 3~5건 단위의 Claude 평가 프롬프트 추가
- 직접 근거, 판단 유보, 교사 최종 판단, 피드백·피드포워드 규칙 추가
- 3차시 연수 적용안 추가

## 설계 원칙

- 점수는 참고값이며 교사 판단을 대체하지 않는다.
- 챗봇 활동과 NIE 기사 댓글은 별도 활동으로 평가한다.
- 활동 간 연결은 점수 합산이 아니라 다음 활동을 위한 피드포워드로 사용한다.
- 실제로 생성하지 않은 Notion 폼·링크·QR은 생성되었다고 보고하지 않는다.
- 개인정보와 원문을 보존하고, 근거가 부족하면 보류한다.

## 검증

- `quick_validate.py`로 Codex 스킬 검증 통과
- `git diff --check` 통과

## 연수 적용 결과

참가자는 프로젝트 전체를 공유받지 않고 독립 스킬만 설치한다. 자신의 Notion 수업자료 링크와 학생 결과물을 입력하여 평가 목표, 문항, 루브릭, 노션폼, 평가 프롬프트, 학생별 피드백과 다음 활동 방향을 완성한다.
