# PR: Notion × Claude 평가 준비·자동채점 스킬 연계

## 요약

초보 교사가 자신의 Notion 수업자료로 평가를 준비하고 실제 학생 결과물을 자동채점한 뒤 교사 검토와 다음 수업 설계까지 이어갈 수 있도록 두 개의 독립 스킬과 배포 패키지를 추가한다.

```text
notion-claude-assessment-prep
성취기준·수업 의도 → 문항·루브릭 → 폼·평가 DB → assessment-spec-v1 승인

notion-claude-assessment-grader
승인 명세 검증 → 시험 채점 → 자동채점 기록 → 교사 검토 → 다음 수업 제안
```

## 주요 변경

- Codex와 Claude Code용 평가 준비 스킬 추가
- Codex와 Claude Code용 자동채점 스킬 추가
- 1번 스킬의 범위를 평가 준비와 실행 명세 생성으로 정리
- `assessment-spec-v1` 인계 규격 추가
- 활동 ID, 루브릭 버전, 평가 기준 ID, Notion 속성 매핑, 판단 유보 조건, 수정 금지 속성 명시
- 2번 스킬이 승인된 명세만 실행하도록 검증 절차 추가
- 1~3건 시험 채점 후 3~5건 단위의 자동채점 절차 추가
- 기사·지문 원문이 없을 때 이해 영역을 낮은 점수 대신 판단 유보로 처리
- 평가 실행 ID, 루브릭 버전, 재채점 여부, 이전 결과 보존 규칙 추가
- 자동채점 이후 교사의 유지·수정·보류 검토를 2번 스킬에 통합
- 학급 공통 경향과 다음 수업 활동 제안 추가
- 개별 ZIP과 두 스킬 묶음 ZIP 제공
- ZIP 설치 안내, 3차시 연수 적용안, NIE 파일럿 문서 추가

## 과정중심평가 대시보드 반영

- 수업활동마다 `assessment-spec-v1` 평가설계 저장 및 교사 승인
- 성취기준, 평가목표, 핵심 질문, 학습 증거, 판단 보류 조건 입력
- 실제 Notion 학생·결과물·피드백 속성명 매핑
- 승인된 평가설계가 없으면 AI 채점 차단
- 최초 1~3건 시험 채점과 이후 채점 단계 구분
- 루브릭 버전과 AI 실행 ID 저장
- AI 피드백과 다음 활동용 피드포워드 동시 생성
- 교사가 결과를 유지·수정·보류하여 최종 검토
- 서로 다른 활동은 별도 평가설계를 사용하며 점수를 자동 합산하지 않음

## 안전 원칙

- 학생 원문과 기존 Relation은 수정하지 않는다.
- AI 점수·근거·피드백과 교사 최종 판단을 분리한다.
- 교사 승인 없이 교사 점수, 교사 확인, 학생기록을 확정하지 않는다.
- 챗봇 활동과 NIE 기사 댓글을 같은 기준으로 합산하지 않는다.
- 근거 부족·원문 누락·지문 불일치는 판단 유보 또는 처리 보류로 남긴다.
- 재채점은 명시적 요청이 있을 때만 하며 이전 AI 결과를 보존한다.
- 개인 학생 자료와 실제 Notion 링크는 배포 ZIP에 포함하지 않는다.

## 연수 적용

1차시는 평가 목표·문항·루브릭과 실행 명세를 만든다. 2차시는 Notion 폼과 평가 DB를 준비한다. 3차시는 결과물 1~3건을 시험 채점하고, 승인 후 자동채점·교사 검토·피드포워드를 실행한다.
