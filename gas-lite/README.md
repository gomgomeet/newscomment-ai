# 교사용 경량 질문챗봇 Apps Script

이 폴더는 기존 공통 체험용 `gas/`와 별개의 Apps Script 프로젝트다. 교사에게는 이 코드를 직접 설명하지 않고, 코드가 연결된 Google Sheet 사본을 제공한다.

## 권장 연수 진행 순서

1. 강사가 이 경량 교사앱에 수업자료와 평가 설계를 미리 입력해 학생용 챗봇을 완성한다.
2. 1차시에는 연수생이 강사의 챗봇에 학생 역할로 참여해 질문, 근거 확인, 생각 수정, 대화 종료와 평가 기록을 먼저 체험한다. 이때 연수생 개인 API는 요구하지 않는다.
3. 체험 후 강사가 설정 화면과 결과 Sheet를 열어 학생 활동이 평가 근거로 연결되는 과정을 보여준다.
4. 2차시부터 연수생이 같은 경량앱의 개인 사본을 받아 자신의 API, 성취기준, 평가기준과 수업자료를 입력해 자기 챗봇을 만든다.
5. 3차시에는 학생 링크 배포, 자동 평가 초안 확인, 교사 검수와 최종 평가를 실습한다.

핵심은 `강사 완성본으로 학생 체험 → 같은 앱의 교사 구조 확인 → 각자 자기 챗봇 제작` 순서다. 체험용과 제작용의 화면·대화 엔진을 같게 유지해 초보 연수생의 설정 부담을 줄인다.

## 개인 제작 단계에서 연수생이 보는 순서

아래 절차는 강사의 완성본으로 진행하는 1차시 체험과 구조·평가 흐름 설명을 마친 뒤, 연수생이 각자 받은 사본에서 진행한다.

1. 배포용 Google Sheet 사본 만들기
2. `경량 질문챗봇 → 1. 최초 준비`
3. `2. 교사 설정 열기`
4. 개인 API 연결
5. 목표 → 성취기준 → 평가기준 → 평가 근거 입력
6. 수업자료와 평가/자료 탐색 모드 입력
7. 설정 저장 및 준비 상태 확인
8. 학생 웹앱에서 `99-999`로 미리보기
9. 학생용 `/exec` 주소만 배포
10. `3. 학생 현황·평가 검수`에서 교사 최종 평가

## 운영자가 배포본을 만들 때

1. 중앙 웹서비스의 `/api/lite-engine/plan`과 `/api/lite-engine/finalize`를 배포한다.
2. `EngineClient.js`의 `LITE_CENTRAL_ENGINE_URL_`에 HTTPS 운영 주소를 넣는다.
3. 빈 Google Sheet에 이 폴더의 파일을 연결한다.
4. 웹앱은 실행 사용자를 `배포 사용자`, 접근 사용자를 `모든 사용자`로 배포한다.
5. Sheet의 `1. 최초 준비`를 실행해 교사 접근 토큰과 다섯 시트를 만든다.
6. 운영용 값이 남지 않은 깨끗한 템플릿을 사본 만들기 링크로 공유한다.

교사 API 키는 Script Properties에 저장되므로 Google Sheet 사본에는 포함되지 않는다. 각 교사가 자신의 사본에서 직접 입력해야 한다.
학생 반-번호는 본인 인증값이 아니라 익명 기록 표지다. 대화·자동평가는 브라우저 탭별 기기값으로 분리되므로 같은 번호를 다른 기기에서 입력해도 기존 대화는 노출되거나 점수가 합쳐지지 않으며, 교사 대시보드에 중복 접속으로 표시된다. 수업 중 번호 입력은 교사가 안내·확인하고, 원격·무감독 배포에는 명부별 PIN 또는 학교 인증을 후속 적용한다. 입장만으로는 Sheet에 행을 만들지 않고 첫 질문을 보낼 때 시작 질문과 첫 턴을 함께 기록한다.

## 데이터 경계

- 중앙 엔진으로 전송: 익명 세션 키, 수업·평가 설정, 가림 처리한 학생 발화, 최근 대화
- 중앙 엔진으로 전송하지 않음: 교사 API 키, Google Sheet ID, 교사 이메일
- 교사 Sheet에 저장: 수업자료, 학생 대화, 자동 판단 초안, 교사 최종 판단과 향상 방법
- 학생 화면에 제공하지 않음: API 키, 평가기준 원문, 수준별 루브릭, 교사 피드백

## 아직 최종 배포하지 않는 조건

- `LITE_CENTRAL_ENGINE_URL_`가 비어 있음
- 준비 점검에서 중앙 엔진 또는 학생용 배포가 빨간색임
- 교사 개인 API로 실제 응답을 확인하지 않음
- `99-999` 미리보기를 하지 않음
- 초보 교사 사용성 및 학생 역할 30명 동시 접속 실증을 하지 않음

로컬 점검은 저장소 루트에서 `npm run test:gas-lite`로 실행한다.
