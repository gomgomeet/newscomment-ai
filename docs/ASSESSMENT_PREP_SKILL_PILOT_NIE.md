# 평가 준비 스킬 파일럿: NIE 기사 의견 쓰기

## 파일럿 목적

독립 배포 스킬이 초보 교사의 실제 평가 준비 흐름을 끝까지 지원하는지 확인한다. 이 문서는 연수용 파일럿이며, 아래 학생 응답은 실습 예시다.

## 1. 스킬에 제공할 입력

```text
수업자료 링크: {교사가 제공하는 Notion 기사 페이지 또는 기사 DB 링크}
학생 결과물 링크: {교사가 제공하는 Notion 제출물 DB 링크}
평가 DB를 만들 위치: {교사가 제공하는 Notion 페이지 링크}

교과·학년: 국어 4학년
활동명: 위기 동물 보호 기사 읽고 자신의 생각 쓰기
성취 목표: 글의 중심 생각을 파악하고 위기 동물을 보호하기 위한 자신의 생각을 표현한다.
수업 의도: 기사 속 사례를 이해하고, 자신의 의견을 기사 내용과 연결하여 근거 있게 쓴다.
결과물 형식: 서술형 응답 3개와 자기평가
점수 목적: 교사 피드백을 위한 참고 점수
```

## 2. 기대하는 평가 준비 산출물

스킬은 먼저 다음 산출물을 제시한다.

- 중심 생각 파악 문항 1개
- 기사 속 동물의 상황 이해 문항 1개
- 위기 동물 보호에 대한 의견과 근거 문항 1개
- 문항별 4수준 루브릭
- 학생용 자기평가 체크리스트
- 교사 관찰 항목
- 평가 DB 최소 속성
- 학생용 노션폼 질문
- 같은 활동 결과물 3~5건을 처리하는 Claude 프롬프트

## 3. 파일럿 결과물 묶음

```text
[NIE-001 / S-01]
동물원은 동물을 보여 주는 곳이 아니라 아픈 동물을 보호하는 곳이어야 한다고 생각합니다. 기사에서 바람이가 좁은 곳에서 살다가 보호시설로 옮겨졌기 때문입니다.

[NIE-002 / S-02]
동물은 불쌍합니다. 동물원을 없애야 합니다.

[NIE-003 / S-03]
기사에서 위기 동물들이 보호받는다는 내용을 읽었습니다. 동물원은 동물이 편안하게 지낼 수 있도록 공간을 넓게 만들고 사람들에게 동물을 보호하는 방법을 알려 주어야 합니다.
```

## 4. 예상되는 학생별 출력

### NIE-001

- 직접 근거: 보호 공간에 대한 주장과 바람이의 이동 사례를 연결함
- 참고 판단: 기사 내용 이해 3, 의견 연결 3, 의견 표현 3
- 피드백: 기사 속 사례를 근거로 자신의 생각을 분명하게 표현했습니다. 다음에는 동물에게 필요한 환경을 한 가지 더 설명해 보세요.
- 피드포워드: 보호시설의 조건을 질문으로 만들고 다음 글에 반영하기

### NIE-002

- 직접 근거: 동물 보호에 대한 의견은 있으나 기사 속 구체적 내용이 없음
- 참고 판단: 기사 내용 이해 판단 유보, 의견 연결 1, 의견 표현 2
- 보류 사유: 짧은 응답만으로 기사 이해 여부를 확정하기 어려움
- 피드백: 동물원을 없애야 한다고 생각한 까닭을 기사 속 내용과 함께 써 보세요.
- 피드포워드: 기사에서 기억에 남은 동물의 상황 한 가지 찾기

### NIE-003

- 직접 근거: 위기 동물 보호라는 기사 주제를 파악하고 공간과 교육이라는 대안을 제시함
- 참고 판단: 기사 내용 이해 3, 의견 연결 3, 의견 표현 4
- 피드백: 기사 주제와 자신의 해결 방법을 잘 연결했습니다. 다음에는 왜 그런 환경이 동물에게 필요한지 사례를 덧붙여 보세요.
- 피드포워드: 자신의 해결 방법을 기사 속 동물 사례와 연결해 설명하기

## 5. 교사 검토 기록

Claude의 점수는 참고값으로만 둔다. 교사는 실제 기사 원문과 학생 응답을 대조하여 다음을 확인한다.

- 학생이 실제로 기사 속 내용을 사용했는가
- 의견과 근거의 연결이 학생의 문장에 드러나는가
- 짧은 응답을 낮은 성취로 단정할 충분한 근거가 있는가
- 피드백이 문장 고치기가 아니라 다음 행동을 제시하는가
- 피드포워드가 다음 활동에서 확인할 새 증거로 이어지는가

## 6. 파일럿 통과 기준

- 활동별 결과물을 분리하여 처리한다.
- 각 판단에 직접 근거가 있다.
- 근거 부족을 낮은 점수로 자동 변환하지 않는다.
- AI 초안과 교사 판단이 분리된다.
- 학생별 피드백과 다음 활동 방향이 함께 나온다.
- Notion 링크가 없으면 평가 완료가 아니라 준비 단계로 멈춘다.

## 다음 파일럿

이 파일럿이 통과하면 실제 익명화 자료 3~5건으로 반복한다. 이후 챗봇 활동을 별도 활동으로 테스트하여 활동별 평가 기준과 피드포워드가 섞이지 않는지 확인한다.
