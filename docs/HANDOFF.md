### 진행 중: lib/questioning-thinking-card.ts (브랜치 claude/thinking-card-simulation)

사용자 요청: 배경 지식 카드를 "AI가 알아서 만드는 목록"이 아니라 **학생 관점
시뮬레이션을 거쳐 만드는 절차**로 코드화.

구현: 학생 페르소나 6개(사실 확인/낱말 이해/까닭 탐색/근거 의심/경험 연결/
범위 밖 관심)로 질문 생성 → 각 질문이 **본문에서** 답 가능한지 판정
(불용어 제외 + 핵심어 2개 이상 일치) → 답 가능하면 근거 문장 표시, 불가하면
'함께 확인할 질문'으로 분류 → 오개념 주의(수치 2개 이상이면 상관≠인과 경고
자동 추가) → 교사 체크리스트 생성. formatThinkingCard()로 검토용 문서 출력.

설계 원칙: 지문에 없는 사실을 만들지 않음. 근거는 학생이 실제 읽는 본문에서만
찾고, 교사 요약에 걸린 것은 근거로 인정하지 않음(본문 없는 위치 안내형 자료일
때만 요약 사용). 이 규칙 덕에 테스트에서 6/6 → 4/6으로 정직해짐.

검증: typecheck 통과. 샘플 지문으로 동작 확인(4/6 답 가능, 2개 함께 확인).
