# 과정중심평가 Claude 스킬팩

이 문서는 교사가 Notion, Claude, Google Sheets, PDF/Word 제출물을 활용해 학생 산출물을 과정중심평가 증거로 해석할 때 바로 복사해 쓸 수 있는 절차와 프롬프트 묶음이다.

## 1. 스킬팩의 목적

Claude에게 “평가를 대신하게” 하는 것이 아니라, 교사가 평가하기 전에 자료를 정리하고 판단 근거를 찾게 하는 것이 목적이다.

사용 원칙:

- 점수보다 평가 증거를 먼저 찾는다.
- 학생의 원문 표현과 교사 판단을 분리한다.
- Claude 초안과 교사 최종 판단을 분리한다.
- 세특 초안에는 반드시 실제 산출물 근거를 붙인다.
- 민감한 개인정보는 넣지 않는다.

## 2. 전체 사용 흐름

```text
1. 학생 산출물 모으기
   Notion 댓글, 챗봇 대화, Google Sheets 로그, PDF/Word 제출물

2. 개인정보 줄이기
   이름은 번호나 별칭으로 바꾸고, 민감한 가정사·건강 정보 등은 제거

3. 평가 기준 제시하기
   성취기준, 루브릭, 수업 목표, 교사가 보고 싶은 평가 증거 제공

4. Claude에게 증거 정리 요청하기
   점수 산출보다 출처별 근거, 강점, 보완점, 다음 피드백 요청

5. 교사가 확인하기
   원자료와 대조하고, 과장·오판·근거 부족 부분 수정

6. Notion 평가 포트폴리오에 기록하기
   Claude 초안, 교사 수정, 최종 판단, 세특 근거를 분리 저장
```

### 자료 유형을 고르는 규칙

- Notion 페이지: 링크 하나가 학생 한 명의 결과물일 때 페이지 전체 읽기를 사용한다.
- Notion 데이터베이스: 여러 학생이 행으로 모여 있을 때 속성 기반 일괄 가져오기를 사용한다.
- Google Sheets: 최종 답만 보지 말고 학생별 행·탭과 시간 정보를 함께 읽는다.
- 이미지·PDF·Word: 결과 문장뿐 아니라 페이지·문단·영역 위치를 평가 근거에 남긴다.
- 여러 출처를 함께 평가할 때는 출처별 근거를 먼저 분리한 뒤 같은 성취기준 아래에서 종합한다.

Notion 페이지 자동 평가 후 Claude 또는 앱의 초안을 검토할 때는 다음을 추가 확인한다.

- 이미지, PDF, 임베드 블록은 본문 텍스트로 읽히지 않을 수 있다.
- 표와 열 배치가 평문으로 바뀌면서 맥락이 달라지지 않았는지 본다.
- 원본 링크를 열어 AI가 든 근거가 실제 학생 표현인지 확인한다.
- 교사가 확인하지 않은 AI 점수는 최종 평가로 사용하지 않는다.

## 3. 산출물 정리 양식

Claude에 넣기 전에 학생 자료를 아래처럼 정리한다.

```text
[학생 식별]
- 학급/번호:
- 활동명:
- 성취기준:
- 수업 목표:

[자료 출처]
1. Notion 댓글:
2. 질문 챗봇 대화 기록:
3. Google Sheets 활동 로그:
4. PDF 보고서 발췌:
5. Word 활동지 발췌:
6. 교사 관찰 메모:

[평가 기준]
- 기준 1:
- 기준 2:
- 기준 3:
- 기준 4:

[요청]
- 점수보다 평가 증거를 먼저 정리해 주세요.
- 불확실한 판단은 단정하지 말고 “교사 확인 필요”로 표시해 주세요.
- 학생에게 줄 피드백은 강점, 보완점, 다음 행동으로 나눠 주세요.
```

## 4. 프롬프트 1: 평가 증거 찾기

```text
다음은 한 학생의 여러 수업 산출물입니다.
이 자료를 과정중심평가 관점에서 분석해 주세요.

중요:
- 점수를 먼저 매기지 마세요.
- 평가 기준별로 확인 가능한 증거를 먼저 찾으세요.
- 근거가 부족한 부분은 추측하지 말고 “근거 부족”이라고 표시하세요.
- 교사가 원자료에서 다시 확인해야 할 부분을 따로 표시하세요.

[학생 정보]
학급/번호:
활동명:
성취기준:
수업 목표:

[자료]
Notion 댓글:

질문 챗봇 대화 기록:

Google Sheets 활동 로그:

PDF 보고서 발췌:

Word 활동지 발췌:

교사 관찰 메모:

[평가 기준]
1.
2.
3.
4.

[출력 형식]
1. 출처별 핵심 평가 증거
2. 평가 기준별 확인된 증거
3. 강점
4. 보완이 필요한 지점
5. 근거가 부족하거나 애매한 판단
6. 교사가 원자료에서 확인해야 할 부분
7. 다음 피드백 방향
8. 평가 기준별 향상 방법: 수정 행동, 제안 이유, 완료 확인 기준
9. 학생에게 건넬 재작성 질문 1개
```

## 5. 프롬프트 2: 피드백 초안 만들기

```text
다음 평가 증거를 바탕으로 학생에게 줄 피드백 초안을 작성해 주세요.

조건:
- 학생의 실제 표현이나 산출물 근거를 반영하세요.
- 칭찬만 하지 말고 다음 행동을 제안하세요.
- “잘했다/부족하다”보다 무엇이 어떻게 드러났는지 설명하세요.
- 단정적인 성격 판단은 피하세요.
- 교사가 수정할 수 있도록 문장을 짧고 명확하게 쓰세요.
- 결과물을 대신 작성하지 말고 학생이 직접 고칠 행동을 제안하세요.

[평가 증거]

[평가 기준]

[출력 형식]
1. 강점 피드백
2. 보완 피드백
3. 다음 학습 행동 제안
4. 교사가 확인해야 할 표현
5. 학생에게 바로 전달 가능한 최종 문장 2개
6. 학생이 실행할 향상 행동 2개
7. 향상 여부를 확인할 체크 기준
```

## 6. 프롬프트 3: 재질문·재작성 안내 만들기

```text
다음 학생 산출물을 보고, 학생이 다시 질문하거나 다시 작성할 수 있도록 안내 문장을 만들어 주세요.

조건:
- 정답을 대신 써 주지 마세요.
- 학생이 자기 생각을 더 구체화하도록 질문 형태로 안내하세요.
- 자료 속 근거를 다시 확인하도록 유도하세요.
- 학생 수준에 맞게 부담이 적은 문장으로 쓰세요.

[학생 산출물]

[보완이 필요한 지점]

[출력 형식]
1. 학생에게 건넬 재질문 3개
2. 다시 볼 자료 또는 근거
3. 재작성할 때 지킬 기준
4. 짧은 교사 피드백 문장
```

## 7. 프롬프트 4: 세특 근거 정리

```text
다음 학생 산출물과 교사 피드백을 바탕으로 세특 작성에 활용할 수 있는 근거를 정리해 주세요.

주의:
- 세특을 최종 확정하지 말고 초안으로만 작성하세요.
- 실제 산출물에서 확인되는 행동과 표현을 근거로 쓰세요.
- 과장된 표현, 인성 단정, 확인되지 않은 성장 서사는 피하세요.
- 민감한 개인정보는 포함하지 마세요.
- 교사가 확인해야 할 문장은 따로 표시하세요.

[학생 산출물 요약]

[교사 피드백]

[성취기준 또는 평가 기준]

[출력 형식]
1. 세특 근거로 쓸 수 있는 관찰 사실
2. 세특에 쓰면 위험한 표현
3. 세특 초안 1
4. 세특 초안 2
5. 교사 확인 필요 사항
6. 추가로 확보하면 좋은 증거
```

## 8. 프롬프트 5: Notion 평가 포트폴리오 DB 설계

```text
다음 수업 흐름과 학생 산출물 출처를 바탕으로 Notion 평가 포트폴리오 DB를 설계해 주세요.

목적:
- 학생별로 여러 산출물 링크를 모읍니다.
- 교사가 제출, 평가 대기, 피드백 필요, 재작성 필요, 세특 근거 확보 상태를 빠르게 봅니다.
- Claude 초안과 교사 최종 판단을 분리합니다.

[수업 흐름]

[산출물 출처]
- Notion:
- Google Sheets:
- PDF:
- Word:
- 기타:

[평가 기준]

[출력 형식]
1. DB 필드 목록
2. 각 필드의 목적
3. 필수 보기 5개
4. 필터 조건
5. 교사가 수업 후 5분 안에 확인할 순서
6. 개인정보 보호 주의점
```

## 9. 프롬프트 6: 대시보드 점검

```text
다음 평가 대시보드 설계안을 검토해 주세요.

검토 기준:
- 교사가 다음 행동을 결정할 수 있는가
- 점수보다 평가 증거와 피드백 필요 상태가 잘 보이는가
- Claude 초안과 교사 최종 판단이 분리되어 있는가
- 원자료 링크와 판단 근거가 함께 제공되는가
- 개인정보 노출 위험이 낮은가
- 연수 참여 교사가 10분 안에 이해할 수 있는가

[대시보드 설계안]

[출력 형식]
1. 유지할 점
2. 줄여야 할 점
3. 추가해야 할 필드
4. 위험한 설계
5. 교사 사용 흐름 개선안
6. 한 문장 핵심 조언
```

## 10. Notion 기록 권장 구조

학생별 평가 포트폴리오 DB에는 다음을 분리해 기록한다.

| 구분 | 기록 내용 |
| --- | --- |
| 원자료 | Notion 댓글, 챗봇 로그, PDF/Word 링크 |
| Claude 초안 | Claude가 정리한 평가 증거, 피드백, 세특 초안 |
| 교사 판단 | 교사가 확인·수정한 평가 메모 |
| 다음 행동 | 피드백, 재작성, 재질문, 면담, 완료 |
| 기록 활용 | 세특 반영 가능 여부, 최종 반영 여부 |

## 11. 교사 확인 체크리스트

Claude 결과를 Notion에 붙여 넣기 전에 확인한다.

- 원자료에 없는 내용을 만들어내지 않았는가?
- 학생 표현을 과장하지 않았는가?
- 점수와 피드백이 평가 기준에 연결되는가?
- 학생의 약점만 강조하지 않았는가?
- 다음 행동이 구체적인가?
- 개인정보나 민감 정보가 포함되지 않았는가?
- 교사 최종 판단과 Claude 초안이 구분되어 있는가?

## 12. 연수 운영 팁

- 처음부터 완벽한 대시보드를 만들게 하지 않는다.
- 참가 교사가 자기 수업 후 5분 안에 볼 정보만 먼저 고르게 한다.
- 샘플 학생 자료로 먼저 연습하고, 실제 학생 자료는 익명화 뒤 사용하게 한다.
- Claude의 결과를 “정답”이 아니라 “검토할 초안”으로 다룬다.
- 마지막 활동은 불필요한 컬럼을 줄이는 활동으로 마무리한다.
