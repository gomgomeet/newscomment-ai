# 교사 자료 입력을 줄이는 방법 — 제안 (2026-09-07)

연수에서 교사가 처음부터 끝까지 30분 안에 챗봇을 띄우려면, 가장 오래 걸리는 자리가 **자료 입력**이다. 지금 교사가 채워야 하는 칸은 이렇다.

| 칸 | 지금 | 필수 |
| --- | --- | --- |
| 챗봇 이름 · 교과 · 첫 인사 | 손으로 | 이름·첫 인사 필수 |
| 학년 | 고르기 | 필수 |
| 자료 버전 | 손으로 (`v1` 같은 것) | **필수** |
| 주제·지문 제목 | 손으로 | 필수 |
| 성취기준 | 500자 자유 입력 | 필수 |
| 지문 | 붙여넣기 (30자~12000자) | 필수 |
| 시작 질문 | 손으로 | 필수 |
| 낱말과 쉬운 뜻 | **한 개씩 손으로** 또는 탭 구분 붙여넣기 | 선택이지만 안 하면 답이 얕다 |

보충 설명(KnowledgePack)만 "제안받기"가 있고, **낱말 뜻에는 자동 초안이 없다.** 30개를 손으로 쓰면 20분이 그냥 간다. 아래는 아낄 수 있는 시간이 큰 순서다.

## 오늘부터 되는 것 (코드 수정 없음)

**0. 낱말 목록에 '주제어'를 넣는다.** 단어군을 `주제어`로 해서 글에는 없지만 아이들이 물을 만한 말을 5~10개 넣는다(플라스틱 기사라면 빨대·텀블러·비닐봉지·분리수거·재활용). 승인 낱말이 그대로 관련 질문 판정에 쓰이므로, 넣기 전에는 딴소리로 처리되던 질문이 "글에는 안 나오지만" 답으로 바뀐다. 실측은 `docs/GAS-터미널-작업-순서.md` 11단계 A 결과 표에 있다. 연수 교안 운영 팁에 넣는다.

## 고쳐야 하는 것 — 아끼는 시간이 큰 순서

**1. 낱말 뜻 자동 초안 + 훑어보고 승인 (가장 큼 · 20분 → 5분).**
지문을 저장하면 학년 수준에 맞춘 쉬운 뜻이 미리 채워진 채로 검토 목록에 뜬다. 교사는 훑고 이상한 것만 고친다. 보충 설명이 이미 `generateKnowledgePackDrafts` — 초안 → 검토 → 승인 구조로 되어 있으니 같은 자리에 낱말을 붙이면 된다. 기본은 '전부 승인', 빨간 표시(뜻 없음·학년보다 어려움)만 손보게 한다.

**2. 자료 버전을 손으로 적지 않게 (필수 칸 하나 줄임).**
지금은 `v1`을 교사가 적는다. 버전이 뭔지 모르는 교사가 멈추는 자리다. 지문이 바뀌면 자동으로 올리고(v1→v2) 칸은 고급 설정으로 접는다. 10단계 대화 보관 규칙이 버전에 걸려 있으므로 자동이 오히려 안전하다.

**3. 지문만 붙이면 제목·시작 질문 초안 (필수 칸 둘 줄임).**
지문에서 제목과 시작 질문을 뽑아 채워 준다. 교사는 고치기만 한다. 1번과 같은 호출에 묶으면 한 번으로 끝난다.

**4. 성취기준은 고르고, 챗봇이 무엇을 물을지 그 자리에서 보여 준다.**
학년을 고르면 그 학년군 읽기 성취기준 목록이 뜬다. 고르면 그 아래에 "이 성취기준이면 챗봇은 **중심 생각**을 묻습니다"라고 보여 준다. `buildStandardTargets`가 이미 낱말로 표적을 정하고 있는데(오늘 실증에서 "중심 생각" 한 마디가 `main_idea`를 정했다) 교사는 그걸 모르고 쓴다. 표시만 붙이면 되고, 잘못 고른 것을 저장 전에 알아챌 수 있다.

**5. 저장 옆에 '3턴 미리 보기'.**
지금은 저장 → 배포 → 학생 주소 열기까지 가야 답을 본다. 저장 버튼 옆에서 바로 세 턴을 돌려 답을 보여 주면 왕복이 사라진다. 미리보기는 `99-*` 규칙을 그대로 쓴다(대시보드에 안 잡힌다).

**6. 한 번만 묻는 것은 접어 둔다.**
챗봇 이름·교과·첫 인사는 처음 한 번이면 된다. 자료를 바꿀 때마다 다시 보이지 않게 접는다.

**7. 기사 붙여넣기 청소.**
신문 기사를 그대로 붙이면 기자 이름·사진 설명·구독 안내 줄이 따라온다. 저장할 때 그런 줄을 걷어내고 문단만 남긴다.

## 누가 고치나

`gas/CONTRACT.md` 2절대로 **`Teacher.html`·`Code.js`는 Codex 소유**다. 1~7은 사양만 쓰고 Codex에게 넘긴다. 0번(주제어)은 코드를 고치지 않으므로 교안과 운영 안내에 넣으면 끝이다. 관련 판정을 넓히는 쪽을 코드로 손봐야 한다면 `Signals.js`는 Claude 소유이므로 여기서 한다.

## 권하는 순서

연수 전에 **1 · 2**만 들어가도 자료 입력이 절반으로 줄어든다. **0**은 오늘 바로 교안에 넣는다. 3~7은 11단계 B 배포 리허설에서 실제로 막히는 자리를 재고 나서 정한다.
