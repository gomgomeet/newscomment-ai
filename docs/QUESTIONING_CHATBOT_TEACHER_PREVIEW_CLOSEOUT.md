# 질문 챗봇 교사 미리보기·실배포 마감 기록

작성일: 2026-08-26

기능 배포 커밋: `3ff02fd` (`Add teacher Gemini preview and isolate student profiles`)

프로덕션: `https://newscomment-ai.vercel.app`

## 목적

교사가 학생에게 수업 링크를 배포하기 전에 실제 수업 코드와 Gemini 연결을 사용해 학생 대화를 시험하고, 마음에 들지 않는 응답을 교정한 뒤 해당 수업 챗봇에만 게시할 수 있게 한다. 미리보기 대화는 학생 참여·평가·Notion 기록을 오염시키지 않아야 한다.

## 최종 구현

### 교사 미리보기

- 교사용 보드에 `⑨ 교사 미리보기`를 추가했다.
- `④ 수업 연결 저장`이 완료되면 수업 코드에 묶인 12시간 유효 서명 토큰을 발급한다.
- 미리보기는 자동 시험 번호 `P01`을 사용하며 별도 학생 번호 입력을 요구하지 않는다.
- 현재 보드의 미게시 초안 설정을 실제 Gemini 요청에 전달해 게시 전 상태 그대로 시험한다.
- 응답마다 제공자, 모델, `localFallback: true/false`, 자료 근거 상태, 질문 유형, 중심 대화 동작, 사용 카드 수, 리서치 결합 여부를 표시한다.
- 기존 연결에는 토큰이 없으므로 배포 후 `④ 수업 연결 저장`을 한 번 다시 눌러야 `⑨`가 활성화된다.

### 교사 응답 교정

- 교사는 불만족 답변에서 `이 답변 수정`을 선택할 수 있다.
- 문제를 사실 오류, 문맥 누락, 학생 말 반복, 과도한 길이·질문, 부자연스러운 말투, 의도 오해, 자료 밖 단정 등으로 분류한다.
- 교사가 원하는 답변을 작성하면 동일 학생 발화로 즉시 다시 시험한다.
- 교정 예시는 최대 12개까지 현재 챗봇 동작 설정에 포함한다.
- Gemini는 의미와 상황이 비슷한 발화에만 교정 예시를 참고하며, 지문 근거·개인정보·안전·대필·원문 복사 금지 규칙을 덮어쓸 수 없다.
- `검토한 수정본 학생용으로 게시`를 누를 때만 해당 수업 코드의 `chatbot_config`를 갱신한다.

### 데이터·보안 경계

- 미리보기 대화는 Notion 학생 결과 DB에 저장하지 않는다.
- 학생 질문 기록과 참여 현황에 포함하지 않는다.
- 미리보기 중 생성한 리서치 답을 공용 리서치 카드로 저장하지 않는다.
- 학생 화면의 수업 설정 조회 응답에는 미리보기 토큰을 포함하지 않는다.
- 토큰은 `QUESTIONING_SECRET_ENCRYPTION_KEY`를 이용한 HMAC 서명으로 수업 코드와 만료 시각을 검증한다.
- 게시 API는 수업 코드와 토큰이 일치하는 활성 연결의 설정만 수정하며 Gemini·Notion 비밀값은 변경하지 않는다.

현재 권한 경계는 교사 계정이 아니라 `수업 코드 + 미리보기 토큰`이다. 토큰을 가진 브라우저에서는 해당 수업 챗봇만 수정할 수 있지만, 장기적으로는 `teacher_id` 소유권 검증이 필요하다.

### 학생 정보 정합성 수정

- 같은 브라우저에 남은 이전 학교·반·번호가 새 수업 화면에 노출되던 문제를 수정했다.
- 현재 수업의 학교·반 또는 학급 인원 범위와 맞지 않는 저장 정보는 상단 요약과 채팅 API 전송에서 즉시 제외한다.
- 범위를 벗어난 테스트 번호는 비우고 학생이 현재 수업 번호를 다시 선택하게 한다.
- 실제 배포 화면에서 과거 배포 점검용 학교·번호가 사라지고 새 입력 안내가 표시되는 것을 확인했다.

## 적용 범위

현재 교정 결과는 제작자 공통 정책이 아니라 **선택한 수업 코드의 챗봇에만 적용**된다.

향후 권장 계층은 다음과 같다.

1. 제작자 공통 정책
2. 교사별 정책
3. 수업 코드별 설정

여러 교사의 수정 결과를 전체 챗봇 개선에 활용할 때는 교사가 명시적으로 제출한 사례만 개인정보를 제거해 별도 개선함에 모은다. 제작자 화면에서 유사 사례를 묶고 일반화된 규칙 후보를 만든 뒤, 회귀평가·일부 수업 시험 적용·제작자 승인을 거쳐 버전으로 배포해야 한다. 개별 교사의 원문 교정을 전체 챗봇에 자동 적용해서는 안 된다.

## 오늘 수업 운영 순서

1. 교사용 보드에서 수업 자료, Gemini, Notion, 학급 정보를 확인한다.
2. `④ 수업 연결 저장`으로 수업 코드를 만들거나 기존 연결을 갱신한다.
3. `⑧ 모두 적용 및 노션 저장`을 실행한다.
4. `⑨ 교사 미리보기`에서 `Gemini 실응답 · localFallback: false`를 확인한다.
5. 필요한 답변을 교정하고 다시 시험한 뒤 학생용으로 게시한다.
6. `https://newscomment-ai.vercel.app/questioning-chatbot?lesson=<lesson-code>` 형식의 주소를 학생에게 배포한다.
7. 학생은 현재 수업의 번호를 선택하고 저장한 뒤 채팅을 시작한다.
