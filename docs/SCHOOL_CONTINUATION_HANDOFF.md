## 학교에서 첫 번째로 할 일

실제 자동채점부터 시작하지 않는다. 먼저 1번 스킬로 한 활동의 평가 실행 명세를 만든다.

추천 첫 활동: `NIE 기사 읽고 자신의 생각 쓰기`

준비할 자료:

- 수업자료 또는 기사 Notion 링크
- 학생 결과물 DB 링크
- 평가 결과를 기록할 DB 링크
- 학생 명단 DB 링크 또는 비식별 학생 ID 사용 방식
- 성취기준과 수업 의도
- 익명화 결과물 3~5건

첫 실행 문장:

```text
notion-claude-assessment-prep 스킬을 사용해서 이 NIE 활동의 평가를 준비해줘.
필요한 Notion 링크와 정보를 먼저 확인하고 assessment-spec-v1 명세까지 만들어줘.
```

## 실행 순서

1. 1번 스킬이 제안한 문항과 루브릭을 교사가 검토한다.
2. Notion의 실제 학생 ID·결과물·기사 연결·AI 기록 속성명을 명세에 넣는다.
3. `승인 상태`를 `승인`으로 바꾼다.
4. 2번 스킬로 1~3건만 시험 채점한다.
5. 기사 원문, 학생 원문, 직접 근거, 점수, 피드백을 대조한다.
6. 이상이 없으면 같은 활동 결과물을 3~5건씩 처리한다.
7. 판단 유보·낮은 확신도·재채점 행을 교사가 우선 검토한다.
8. 학급 공통 어려움에서 다음 수업 활동 한 가지를 정한다.

자동채점 실행 문장:

```text
notion-claude-assessment-grader 스킬을 사용해 승인된 assessment-spec-v1 명세를 검증해줘.
먼저 결과물 1~3건을 시험 채점하고 DB에 쓰기 전에 결과를 보여줘.
```

## 통과 기준

- 동일한 활동과 루브릭만 한 배치에 들어간다.
- 모든 점수에 학생 원문의 직접 근거가 있다.
- 기사 이해 영역은 기사 원문과 함께 평가한다.
- 근거 부족을 자동으로 낮은 점수로 바꾸지 않는다.
- AI 속성만 기록하고 교사·학생 원문 영역은 바뀌지 않는다.
- 재채점 시 이전 AI 결과와 루브릭 버전이 남는다.
- 교사가 유지·수정·보류를 선택할 수 있다.
- 피드포워드가 다음 활동에서 확인할 새 증거를 제시한다.

## 즉시 멈출 조건

- Notion DB의 실제 속성명이 명세와 다름
- 학생 원문이나 교사 점수를 수정하려고 함
- 기사 원문 없이 기사 이해 점수를 확정함
- 서로 다른 활동이 한 배치에 섞임
- 기존 완료 행을 승인 없이 재채점함
- 개인정보가 비식별화되지 않음

이 경우 해당 배치를 기록하지 말고 평가 실행 명세 또는 DB 속성 매핑을 먼저 수정한다.
