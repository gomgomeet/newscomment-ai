# 평가 루브릭 작성 (edu-rubric)

## 이 스킬이 하는 일

활동·성취기준·학년만 받으면, 교사 채점·학생 자기평가·AI 평가에 모두 쓸 수 있는
**완결형 루브릭 문서 한 페이지**를 만든다. 표만 던져 주는 것이 아니라, 영역별
해설과 예시·체크리스트·모범 글까지 갖춘 "바로 수업에 들어가는" 문서를 만든다.

기준 형식은 「✍️ 신문기사 댓글쓰기 평가 루브릭」
(https://app.notion.com/p/3c2c5f01a4a48065bebff764fd39e1d3)이다.

## 실행 경계

- 백워드 설계의 순서를 지킨다: `성취기준 확인 → 평가기준안·루브릭 설계 → 교사 승인·버전 고정 → 학생 활동 → 결과물 평가`.
- 평가기준안과 루브릭이 승인되기 전에는 학생 결과물을 열람하거나 채점하지 않는다.
- 공식 성취기준 코드와 원문은 교사가 제공한 것만 사용한다. 누락되면 제공을 요청하고 추정하거나 만들어 내지 않는다.
- 학생 결과물을 본 뒤 성공기준, 평가 요소, 수준 경계를 유리하거나 불리하게 바꾸지 않는다.
- AI가 만든 문서는 `설계 초안`이며, 교사가 승인한 문서만 `평가 적용본`이다. 승인 시 버전과 날짜를 기록한다.

## 1. 먼저 확인할 것 (없으면 기본값 사용)

| 항목 | 확인 질문 | 기본값 |
| --- | --- | --- |
| 활동 | 무엇을 평가하나? (댓글쓰기, 의견 글, 발표, 보고서…) | 신문기사 의견쓰기 |
| 학교급·학년 | 몇 학년 대상인가? | 초등 4학년 |
| 성취기준 | 연결할 공식 성취기준 코드와 원문이 있는가? | 제공을 요청한다. 없으면 코드 없는 초안임을 표시하고 공식 코드를 추정하지 않는다 |
| 평가 영역 | 몇 개 영역으로 보나? | 3개 (이해 · 연결 · 표현) |
| 수준 척도 | 몇 수준인가? | 4수준 (4 매우 잘함 / 3 잘함 / 2 노력 필요 / 1 더 연습 필요), 총점 = 영역 수 × 4 |
| 용도 | 교사 채점 / 학생 자기평가 / AI 평가 중 무엇에 쓰나? | 셋 다 쓸 수 있게 작성 |

5수준(5~1)이나 0점 포함(0~5), 7요소 확장형(중·고)을 요청하면 척도만 바꾸고
구조는 유지한다.

## 2. 산출물 구조 (순서 고정)

완성 문서는 반드시 아래 일곱 블록을 이 순서로 갖춘다.

1. **🎯 관련 성취기준 콜아웃** — 코드와 성취기준 문장을 그대로 인용
2. **도입 문단** — "결과물만 평가하지 않고, 읽기 → 이해 → 연결 → 표현의
   **과정이 드러나도록** 만든 루브릭"임을 2~3문장으로 설명
3. **루브릭 표** — 평가 영역(행) × 수준(열), 표 위에 총점 표기.
   수준 명칭은 `4점 매우 잘함 / 3점 잘함 / 2점 노력 필요 / 1점 더 연습 필요` 고정
4. **영역별 해설** (영역마다 반복):
   - 이 영역에서 보는 것 한 문장 ("기사를 읽었다는 흔적이 있는가?")
   - **낮은 수준 예시 vs 높은 수준 예시** — 실제 학생 말투의 문장을 대비해서 제시
   - **AI가 찾아야 할 평가 증거** — 불릿 3~4개 (예: 기사 핵심 내용 언급,
     구체적 사실 활용, 왜곡 여부)
   - **AI 지시 문장** — "이해도 점수를 줘"가 아니라 "학생 글에서 ~의 근거가 되는
     표현을 찾아라"라고 쓰는 법을 명시
5. **⭐ 학생용 자기평가 체크리스트** — 각 영역을 질문 + □ 체크 문장으로 변환.
   교사용 표와 반드시 분리한다. 체크리스트 자체가 글쓰기 전략이 되게 쓴다
6. **🧑‍🏫 교사 모범 예시 글** — 같은 자료(기사)에 대해 **입장이 다른 샘플 2개** +
   짧은 버전 1개. 이어서 "이 예시가 루브릭을 어떻게 만족하는가" 표
   (루브릭 영역 | 예시 속 증거)
7. **수업 활용 팁 콜아웃** — 샘플 ①②를 나란히 보여 주고 "왜 같은 자료에서 다른
   결론이 나올 수 있을까?"를 발문해, **입장이 아니라 근거가 평가된다**는 원칙을
   학생이 발견하게 하는 팁

## 3. 기술문 작성 원칙 (품질 규칙)

- **입장을 평가하지 않는다.** 찬성/반대·결론이 아니라 자료와 생각의 연결,
  근거의 질을 평가한다.
- **관찰 가능한 증거 중심으로 쓴다.** "이해가 깊다"(불가) → "기사의 핵심 내용을
  자기 말로 언급한다"(가능).
- **수준 간 차이는 행동의 질로 구분한다.** 부사만 바꾼 기술문
  (매우 잘함/잘함/보통…)은 금지. 4점과 3점은 학생 글에서 무엇이 다르게
  보이는지가 달라야 한다.
- **각 수준은 서로 배타적으로.** 한 글이 두 수준에 동시에 해당하지 않게 쓴다.
- **주장 → 이유 → 근거** 구조를 표현 영역의 기본 틀로 쓴다.
- **교사 언어와 학생 언어를 분리한다.** 교사용 표는 정확하게, 학생용
  체크리스트는 "~했어요" 말투로 쉽게.
- **AI 평가에 쓸 때의 안전 규칙**을 문서에 포함한다: 글에 없는 내용을 추측하지
  않는다 · 짧다는 이유만으로 감점하지 않는다 · 불확실하면 낮은 확신도를 표시하고
  교사 검토를 요청한다 · AI 점수는 초안이며 최종 판단은 교사가 한다.

## 4. 척도 변형 규칙

- **기본**: 영역당 1~4점 (총 12점, 3영역 기준)
- **0~5점형**: 노션 신문기사 수업 패키지의 3영역(기사 이해·생각 연결·생각 표현,
  총 15점)과 맞출 때. 0점 = 판단 근거 없음
- **5수준형(5~1)**: 수행평가·논술형은 "5 매우 우수"를 신설하고 4수준 기술문을
  상향(맥락 파악, 교차 확인, 예상 반론, 실천 방안 등)해 세분
- **7요소 확장형(중·고)**: 기사 이해와 요약 / 자료 신뢰성·공정성 판단 / 주장
  명확성 / 근거 타당성 / 조직과 표현 / 시민적 관점 / 쓰기 윤리 — 연수 운영
  페이지 2차시 3절의 확장 루브릭 토글을 기준으로 쓴다

## 5. 저장

- 완성 문서는 마크다운으로 만들고, 요청이 있으면 **노션 페이지**로도 저장한다.
  아이콘 ✍️ 또는 📏, 제목은 「(활동명) 평가 루브릭」.
- 노션 저장 위치는 수업 페이지의 하위(학생 공유용이면 읽기 허용) 또는
  연수 운영 페이지 하위로 한다.
