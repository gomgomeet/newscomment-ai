# 노션×Claude로 완성하는 NIE 과정중심평가 대시보드

이 문서는 평가 대시보드, 질문중심 챗봇, NIE Notion 수업, Google Sheets 결과 저장 계획을 하나의 연수 흐름으로 묶기 위한 계획이다.

연수의 목적은 도구 사용법 자체가 아니다. 교사가 학생의 다양한 산출물을 과정중심평가의 증거로 읽고, Claude와 Notion을 활용해 피드백·재작성·세특 근거·다음 수업 설계로 연결하도록 돕는 것이다.

> 학생이 어디에 제출했는가보다, 그 산출물에서 어떤 배움의 증거를 찾고 어떻게 다음 피드백으로 연결할 것인가가 중요하다.

## 연수 확정 방향

이번 연수의 중심 사례는 **Notion NIE 템플릿에 작성된 학생 결과물을 Claude 평가 초안과 교사 최종평가로 연결하는 과정**이다. 질문중심 챗봇, Google Sheets, 이미지·PDF·Word는 평가 증거가 확장될 수 있음을 보여주는 비교 자료로만 소개하고 이번 핵심 실습에는 넣지 않는다.

초보자는 한 학생의 한 페이지를 사용해 다음 흐름을 완주한다.

`NIE 템플릿 복제 → 학생 결과물 v1 확인 → Claude 평가 근거 초안 → 교사 원문 대조와 최종판단 → 향상 행동·재작성 질문 → 결과물 v2 비교`

이 흐름은 `Feed up(성취기준·성공 기준) → Feedback(Claude 근거 초안·교사 확인) → Feed forward(향상 행동·재작성·v2)`의 3F 평가 프로토콜로 설명한다. 평가의 실효성은 자동 점수 자체가 아니라 교사의 판단과 학생의 다음 결과물이 달라지는 것으로 확인한다.

연수 당일 강사용 시간표, 멘트, 성공 기준과 오류 대체 절차는 [노션×Claude NIE 과정중심평가 대시보드 연수 운영 교안](NOTION_CLAUDE_NIE_EVALUATION_TRAINING_RUNBOOK.md)을 기준으로 한다.

현재 웹 평가보드의 자동평가 엔진은 OpenAI API다. 이번 본 수업에서는 엔진을 바꾸지 않고, 평가보드로 Notion 원문을 수집한 뒤 Claude에 직접 넣어 평가 초안을 받고 교사 확인 결과를 보드에 기록한다. Claude API 엔진 전환은 연수 후 심화 숙제로 운영하며, OpenAI 결과를 Claude 결과라고 설명하지 않는다.

실제 수업 사례 자료는 준비 완료 상태다. 합성 골든 케이스는 안전 원칙 설명과 장애 대응용으로 유지하고, 익명화·기관 지침·공개 범위를 최종 확인한 실제 사례를 근거 분석과 v1–v2 변화 시연의 주 자료로 사용한다.

## 1. 현재 프로젝트 문서와의 연결

### 평가 대시보드

`docs/EVALUATION_DASHBOARD_PLAN.md`는 뉴스 댓글 루브릭 평가 화면을 교사의 수업 후 점검 화면으로 키우는 계획이다.

이 문서의 핵심은 다음과 같다.

- 평균 점수보다 진행률과 분포를 먼저 보여준다.
- 교사가 “어디까지 했지”, “누구를 먼저 봐야 하지”, “무엇을 기록으로 남기지”에 답할 수 있어야 한다.
- Claude 초안은 교사 최종 평가와 분리한다.
- `/dashboard/compare`는 Claude 초안과 교사 평가를 비교하는 화면으로 발전시킨다.

### 질문중심 챗봇

`docs/질문챗봇-구현-순서.md`와 PR #41의 방향은 질문 챗봇 결과를 Google Sheets에 저장하고, 교사 보드는 참여 현황만 보여주는 것이다.

- 반별 Google Sheets 파일 하나
- 학생별 대화 탭
- 학급 요약 탭
- 대화 전체를 시간순으로 저장
- 교사 보드에는 참여/미참여, 질문 수, 마지막 갱신 시각만 표시
- 대화 전문과 세특 초안은 공개성이 높은 웹 보드에 표시하지 않음

이 원칙은 연수에서 개인정보와 교사 최종 판단을 설명할 때 중요하다.

## 2. 평가 증거의 출처

과정중심평가의 증거는 하나의 도구에만 남지 않는다. 연수에서는 여러 출처의 산출물을 같은 평가 언어로 읽는 연습이 필요하다.

### Notion NIE 결과물

- 기사 댓글
- 의견 글
- 평가 DB
- 강점, 피드백, 평가 포워드
- 세특 초안 근거

평가 관점:

- 기사 이해
- 생각 연결
- 생각 표현
- 출처 신뢰성과 공정성
- 시민적 관점
- 글쓰기 윤리

### 질문중심 챗봇 결과물

- 처음 질문
- 질문 유형
- 챗봇 답변 요약
- 자료 속 근거 확인
- 고쳐 쓴 질문
- 성찰 기록
- AI 활용 태도

평가 관점:

- 질문의 명확성
- 질문의 확장
- 근거 기반 사고
- 질문 수정
- 성찰
- AI를 정답 작성 도구가 아닌 탐구 도구로 사용하는 태도

### Google Sheets 결과물

- 학급별 요약 탭
- 학생별 대화 전체 탭
- 시간순 대화 로그
- 제출·참여 현황
- 질문 수와 활동 흐름

평가 관점:

- 참여 지속성
- 질문-응답 흐름
- 수정 흔적
- 대화 속 이해 변화
- 누락 학생 확인

### PDF·Word 등 파일 제출물

- PDF 보고서
- Word 활동지
- Word 초안과 최종본
- 발표 자료
- 이미지·캡처 자료

평가 관점:

- 완성 결과물의 수준
- 초안과 최종본의 변화
- 피드백 반영 여부
- 근거 제시 방식
- 자기 언어로 설명한 흔적
- 다음 학습으로 이어질 지점

## 3. 평가 대시보드 설계 원칙

### 점수판이 아니라 교사용 의사결정 점검판

대시보드는 학생을 점수로 정렬하는 화면이 아니라, 교사가 다음 행동을 결정하는 화면이어야 한다.

대시보드가 답해야 할 질문:

- 누가 아직 참여하지 않았는가?
- 누가 제출했지만 평가가 필요한 상태인가?
- 누구에게 피드백이 필요한가?
- 누가 재작성 또는 재질문이 필요한가?
- 어떤 학생의 산출물이 좋은 예시가 될 수 있는가?
- 세특 근거로 쓸 수 있는 구체적 표현은 어디에 있는가?
- Claude의 초안 중 교사가 반드시 확인해야 할 부분은 무엇인가?

### Claude 초안과 교사 최종 판단 분리

Claude 평가는 최종 평가가 아니라 교사가 검토할 초안이다.

대시보드와 DB에는 다음을 분리해 기록해야 한다.

- 원자료
- AI 분석 초안
- 교사 수정
- 교사 최종 판단
- 최종 반영 여부

### 원자료 링크와 판단 근거 표시

Claude가 만든 피드백이나 세특 초안은 반드시 근거와 함께 보여야 한다.

권장 필드:

- 원자료 링크
- 근거 출처: Notion 댓글, 챗봇 대화, Google Sheets 로그, PDF, Word
- 평가 기준 태그
- 근거 문장
- Claude 초안
- 교사 확인 메모

## 4. 후속 확장: Notion 평가 포트폴리오 DB 설계

학생별 다출처 결과물을 장기간 누적하려는 후속 연수에서는 Notion 평가 포트폴리오 DB를 설계할 수 있다. 이번 초보자 연수에서는 Notion을 학생 활동 원자료 공간으로, 평가보드를 Claude 초안과 교사 최종판단 공간으로 사용하며 별도의 포트폴리오 DB 제작을 핵심 실습에 넣지 않는다.

- 학생 ID
- 학급
- 활동명
- 제출 상태
- 평가 상태
- 피드백 상태
- Notion 결과물 링크
- Google Sheets 로그 링크
- PDF 제출물 링크
- Word 제출물 링크
- 평가 기준 태그
- 평가 증거 요약
- Claude 분석 초안
- 교사 피드백
- 교사 최종 판단
- 세특 반영 가능 근거
- 최종 반영 여부

권장 보기:

- 학급 전체 보기
- 학생별 보기
- 활동별 보기
- 피드백 필요 보기
- 재제출 요청 보기
- 세특 근거 보기

## 5. Claude 실습 프롬프트

교사가 바로 복사해 쓸 수 있는 전체 프롬프트 묶음은 [과정중심평가 Claude 스킬팩](PROCESS_ASSESSMENT_SKILL_PACK.md)에 따로 정리한다. 이 장은 연수 흐름에서 꼭 필요한 기본 프롬프트만 남긴다.

### 평가 증거 분류

```text
다음 학생 산출물을 과정중심평가 관점에서 분석해 주세요.
점수를 먼저 매기지 말고, 평가 증거를 먼저 찾아 주세요.

자료 출처:
- Notion 댓글:
- 챗봇 대화 기록:
- Google Sheets 활동 로그:
- PDF 보고서 발췌:
- Word 활동지 발췌:

분석 기준:
- 성취기준 관련성
- 개념 이해
- 자료 해석
- 주장과 근거
- 질문의 질
- 수정과 성찰
- 피드백 반영
- 다음 학습 필요점

출력 형식:
1. 출처별 핵심 평가 증거
2. 기준별 강점
3. 기준별 보완점
4. 교사가 확인해야 할 불확실한 판단
5. 피드백 문장 초안
6. 세특 근거로 활용 가능한 표현
7. 다음 수업 또는 다음 과제 제안
```

### 대시보드 설계

```text
다음 Notion DB와 Google Sheets 컬럼을 바탕으로 교사용 과정중심평가 대시보드를 설계해 주세요.

대시보드의 목적은 평균 점수 비교가 아니라, 교사가 학생의 참여 상태, 평가 대기 상태, 피드백 필요 여부, 세특 근거를 빠르게 확인하는 것입니다.

출력 형식:
1. 대시보드 상단 요약 지표
2. 학생별 목록에 필요한 컬럼
3. 필터와 보기
4. 교사가 하루 수업 후 확인할 순서
5. 개인정보 보호와 교사 최종 판단 원칙
```

### 세특 초안

```text
다음 학생 산출물과 교사 피드백을 바탕으로 세특 초안을 작성해 주세요.

조건:
- 학생의 실제 산출물 근거를 포함할 것
- 과장된 표현을 피할 것
- 성취기준과 연결할 것
- 교사가 수정할 수 있도록 판단 근거를 함께 제시할 것
- 민감한 개인정보는 포함하지 말 것

출력 형식:
1. 근거 요약
2. 세특 초안
3. 교사 확인 필요 문장
4. 더 필요한 추가 증거
```

## 6. 연수 교안 구조

### 이번 수업의 중점 실습: Notion 링크에서 바로 평가하기

이번 연수의 기본 경로는 `NIE 기본 템플릿 제공 → 공동 연수용 Notion 워크스페이스에 복제 → 평가보드 연결`이다. 현재 평가보드는 하나의 서버 `NOTION_API_KEY`를 사용하므로 참가자별 개인 워크스페이스 연결은 지원하지 않는다. 교사별 개인 연결과 Notion 템플릿 자동 생성은 후속 개발로 남긴다. 상세 안내는 [NIE Notion 복제 템플릿과 평가보드 연결 안내](NIE_NOTION_TEMPLATE_LINKING_GUIDE.md)를 사용한다.

참여자는 복제한 샘플 학생 Notion 페이지를 이용해 다음 25~30분 흐름을 완주한다.

1. 강사가 제공한 NIE 기본 템플릿을 지정된 공동 연수용 Notion 위치에 복제한다.
2. 평가 대시보드에서 수업활동과 성취기준 루브릭을 연결한다.
3. 학생 실명 대신 학급·번호 또는 별칭을 입력한다.
4. 복제한 학생 페이지의 `공유 → 연결`에서 평가 앱 통합을 추가한다.
5. `복제한 Notion 템플릿 연결`에 링크를 붙여넣고 Claude 평가 초안 생성을 선택한다.
6. 원본 Notion 페이지와 기준별 Claude 근거를 나란히 확인한다.
7. 기준별 `향상 방법 제안`이 학생이 직접 실행할 수 있는 행동인지 확인한다.
8. 근거가 맞는 점수와 향상 제안만 교사 평가에 반영하고, 종합 피드백을 수정해 저장한다.
9. v1을 보존하고 v2 수정본을 만들어 성취기준별 변화를 확인한다.

실습 성공 기준은 “Claude 점수가 나왔다”가 아니라 다음 여섯 가지다.

- 페이지 전체 결과물이 평가자료로 들어왔는가
- 각 판단이 성취기준과 원문 근거에 연결되는가
- 이미지·첨부처럼 읽지 못한 부분을 교사가 확인했는가
- Claude 초안과 교사 최종 평가가 분리되어 저장되는가
- 향상 제안에 수정 행동과 완료 확인 기준이 포함되는가
- Claude가 학생 결과물을 대신 다시 써 주지 않고 재작성 질문을 제공하는가

Google Sheets와 이미지·PDF·Word는 같은 평가 절차를 설명하는 비교 사례로 다루고, 후속 차시에 실제 입력 경로를 구현·실습한다.

### 1차시: 준비된 실제 NIE 결과물에서 평가 증거 찾기

- 합성 골든 케이스로 안전 원칙과 근거 찾기 방법 확인
- 준비된 익명 실제 사례의 v1 원문 확인
- 성취기준과 성공 기준에 맞는 근거 문장 표시
- 같은 자료에 대한 Claude 초안과 교사 판단 비교
- 근거 부족 판단을 `교사 확인 필요`로 수정

산출물:

- 근거–성취기준 연결표
- Claude 초안 대조표
- 교사 수정 판단 1개

### 2차시: Notion NIE 결과물을 Claude로 평가하고 평가보드에 기록하기

- 공동 연수용 Notion 공간에 NIE 기본 템플릿 복제
- 공통 기사와 샘플 학생 결과물 v1 작성
- Notion 통합 연결과 학생 페이지 링크 입력
- 익명화한 원문과 루브릭으로 Claude 평가 초안 생성
- Claude 근거와 학생 원문을 대조한 뒤 교사 확인 결과 기록
- 원본 페이지에서 누락 블록·이미지·첨부 확인

산출물:

- 학생 결과물 v1 Notion 페이지
- Claude 평가 초안
- 교사 확인 필요 표시

### 3차시: 교사 최종판단과 향상 피드백으로 연결하기

- Claude 초안의 점수·근거·피드백 수정
- 학생이 실행할 향상 행동과 완료 확인 기준 작성
- 답을 대신 주지 않는 재작성 질문 작성
- v1을 보존하고 v2 수정본 생성
- 학급 리포트에서 다음 수업에 다시 볼 성취기준 선택

산출물:

- 교사 최종평가
- 향상 행동과 재작성 질문
- 학생 결과물 v2
- 다음 수업 피드백 계획

### 선택 확장: 다출처 평가 포트폴리오

Google Sheets, 이미지·PDF·Word, 질문중심 챗봇 기록은 후속 연수에서 학생·성취기준별로 묶는다. 이번 연수에서는 자동평가가 가능한 것처럼 시연하지 않고 향후 입력 경로로만 소개한다.

## 7. 개발 작업으로 이어질 지점

연수 설계를 실제 앱으로 옮기는 진행 상태와 우선순위는 다음과 같다.

1. 교사 평가와 Claude 초안 분리 — **저장 구조 완료**
   - `evaluations.source`
   - `teacher-manual`
   - `ai-draft`
2. 수업활동별 채점 진행률과 남은 평가 필터 — **완료**
   - 댓글 수, 교사 평가 수, 남은 수, 진행률
   - `안 한 것만 보기`
3. Notion 페이지 링크 바로 평가 — **구현 완료, PR #45 검토 중**
   - 페이지 전체 중첩 블록 읽기
   - 동일 페이지 중복 방지
   - 성취기준별 자동평가 초안 즉시 생성
   - 원본 링크와 AI 근거·교사 최종평가 대조
   - NIE 기본 템플릿 복제와 평가보드 연결 안내
   - 선택 환경변수로 템플릿 복제 버튼 표시
   - 개인 워크스페이스 연결과 템플릿 자동 생성은 후속 개발 범위로 분리
4. Claude 자동평가 엔진 전환 — **연수 후 선택 심화 숙제, 미착수**
   - 현재 OpenAI 평가 생성 경로를 Claude API로 교체 또는 제공자 선택 구조로 전환
   - Claude 모델명과 API 환경변수 추가
   - 구조화 응답, 오류 메시지, 모델 표기와 비용·개인정보 안내 검증
   - 합성 골든 케이스로 Claude 초안과 교사 판단 대조 리허설
5. 프로젝트 학급 리포트 — **구현 완료, PR #45 검토 중**
   - 점수 구간별 분포와 학급 평균
   - 낮은 성취기준과 먼저 확인할 학생
   - 학생 이름을 숨긴 수업 예시 후보
   - Notion 원자료와 평가 작업대 연결
6. Claude·교사 성취기준별 대조 — **화면 구현 완료, 본 수업은 Claude 직접 초안 사용**
   - 정확 일치율과 ±1점 이내 일치율
   - 교사 평균과 AI 평균, 평균 점수 차이
   - 교사 근거와 AI 근거 나란히 보기
   - 일치율이 낮은 기준 우선 확인
7. 학생 결과물 향상 방법 제안 — **화면 구현 완료, 본 수업은 Claude 직접 초안 사용**
   - 성취기준별 향상 행동과 제안 이유
   - 수정 완료 여부를 확인할 성공 기준
   - 학생의 독립적인 수정을 돕는 재작성 질문
   - 이미 잘한 기준을 위한 유지·확장 제안
8. 질문 챗봇 결과 Google Sheets 저장 — **후속**
   - 반별 파일
   - 학생별 탭
   - 요약 탭
   - 대화 전체 시간순 저장
9. 교사 보드 참여 현황 중심 개편 — **후속**
   - 참여/미참여 인원
   - 학생별 질문 수
   - 마지막 갱신 시각
   - Google Sheets 열기 링크
10. 이미지·PDF·Word 입력 — **후속**
   - 이미지 OCR과 교사 확인 위치
   - PDF·Word 전체 본문과 페이지·문단 위치
   - 자동으로 읽지 못한 영역 표시
11. 학생별 평가 포트폴리오와 다출처 증거 연결 — **후속**
   - PDF/Word/Notion/Sheets 링크 필드
   - 평가 증거 요약
   - Claude 분석 초안
   - 교사 최종 판단
   - 세특 근거 표시
