# 클로드 평가 데모

연수의 1차시 `평가기준안 설계`와 2차시 `평가 초안 → 교사 검수 → 최종 결과 저장`을 한 번에 제공한다. 요청이 어느 단계인지 판단해 해당 모듈을 읽고 실행한다.

## 공통 원칙

- `성취기준 확인 → 평가기준안·루브릭 설계 → 교사 승인·버전 고정 → 학생 활동 → 결과물 평가` 순서를 지킨다.
- 공식 성취기준 코드와 원문을 추정하거나 만들어 내지 않는다.
- 승인된 평가기준안을 학생 결과물에 맞춰 소급 변경하지 않는다.
- 학생 결과물은 익명화하고, 원문에 없는 태도·성격·의도를 추정하지 않는다.
- AI 결과는 초안이고 최종 판단은 교사가 한다.
- Notion에 쓰기 전 대상 URL과 `현재값 → 새 값`을 보여 주고 명시적 승인을 받는다.
- 후속 제출물이나 수업 관찰 근거가 없으면 성장을 확인했다고 단정하지 않는다.

## 모듈 선택

### 1차시 · 평가기준안 설계

사용자가 성취기준, 평가 요소, 성공기준, 루브릭, 채점 기준, 자기평가표를 만들거나 다듬으려 하면 [references/01-rubric-design.md](references/01-rubric-design.md)를 읽고 따른다.

승인된 평가기준안이 없는데 학생 결과물을 평가해 달라고 하면 결과물을 열지 말고 이 모듈부터 실행한다. 설계 초안을 만든 뒤 교사 승인과 버전 고정을 기다린다.

### 2차시 · 평가 초안·교사 검수·Notion 저장

사용자가 승인된 평가기준안으로 학생 결과물을 평가하거나, Claude 초안을 검수하거나, 피드백·평가 포워드를 만들거나, 승인 결과를 Notion에 저장하려 하면 [references/02-evidence-review-and-notion.md](references/02-evidence-review-and-notion.md)를 읽고 따른다.

두 단계를 한 요청에서 진행하더라도 1차시 모듈의 교사 승인·버전 고정이 끝나기 전에는 2차시 모듈로 넘어가지 않는다.

## 연결 실패 시 대체 경로

Notion 연결이 없거나 권한이 부족하면 오류를 우회하지 않는다. 교사가 학생 식별정보를 제거한 원문과 승인된 루브릭을 복사·붙여넣기로 제공하도록 안내하고, 결과는 저장용 표 형태로 반환한다.

## 완료 조건

- 1차시: 공식 성취기준, 평가 요소, 수준별 기술문, 학생용 체크리스트가 포함된 초안을 교사가 승인하고 버전을 고정했다.
- 2차시: 모든 판단에 직접 근거가 연결되었고, 교사가 유지·수정·보류를 결정했으며, 승인한 값만 Notion에 저장하고 다시 읽어 검증했다.
