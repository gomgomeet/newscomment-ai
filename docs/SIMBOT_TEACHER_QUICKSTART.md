# simbot 교사 실습 안내

수업자료와 목표를 넣으면 AI가 필수 평가 문항 2개와 문항별 기준표를 만듭니다. 교사가 검토한 문항으로 학생과 대화하고, 답변 분석 결과를 교사가 최종 확인합니다.

**사본 링크는 연수 배포자가 안내합니다.**

배포자는 별도 템플릿의 공유 대상을 확인한 뒤 사본 만들기 링크를 전달하세요. 개인 운영본 주소와 교사 미리보기 주소는 공개 안내에 넣지 않습니다.

배포자가 개인 키·운영 설정·학생 기록을 정리한 **별도 배포용 템플릿**을 사용하세요. **최초 준비와 새 수업 복제는 기존 기록을 삭제하는 기능이 아닙니다.**

1. **내 사본 만들기**
   정리가 확인된 배포용 템플릿 링크에서 Google Sheet 사본을 만드세요. 연결된 Apps Script도 함께 복사됩니다. 학생 기록이 있는 교사 운영본을 그대로 복사해 배포하지 마세요. [Google 안내](https://developers.google.com/apps-script/guides/bound)

2. **최초 준비·권한 승인**
   사본에서 **simbot → 1. 최초 준비**를 눌러 연결된 Apps Script를 실행하고, Google 계정과 요청 권한을 확인해 승인하세요. 메뉴가 보이지 않으면 시트를 새로고침하세요. 이후 설정은 **simbot → 2. 교사 설정 열기**에서 바꿉니다.

3. **개인 AI 연결**
   교사 설정 위쪽 **AI 연결**에 본인의 OpenAI API 키를 입력하고 **키 저장 → 연결 확인**을 누르세요. AI 생성과 답변 분석에는 연결한 API 사용료가 발생합니다.

4. **평가 문항 2개 만들기**
   **1단계**에서 평가모드와 수업 목표 또는 성취기준을 입력하고, **2단계**에 수업자료 본문을 붙여 넣으세요. **3단계**에서 **필수 평가 문항 2개**와 평가 수준 **3·4·5단계** 중 하나를 먼저 선택하세요. **AI로 필수 문항 2개 생성 → 문항 수정 → 이 2문항으로 확정** 순서로 진행하세요.

5. **문항별 기준표 검토·승인·저장**
   **확정 문항의 분석 기준표 생성**을 누르세요. 선택한 수준은 **3단계(도달·성장 중·도움 필요)**, **4단계(매우잘함·잘함·보통·노력요함)**, **5단계(A~E)**로 표시됩니다. 핵심 답변·자료 근거·수준별 기준·예상 답변·보충 질문을 검토·수정하고 승인란에 체크하세요. **4단계**에서 숫자 6자리 학생 참여코드를 정한 뒤 저장하세요.

6. **처음 한 번 웹앱 배포**
   사본의 **확장 프로그램 → Apps Script → 배포 → 새 배포 → 웹 앱**을 여세요. 실행 사용자는 **나**, 접근 권한은 **학교가 허용하면서 학생이 접속할 수 있는 범위**로 선택하고 배포하세요. 발급된 `/exec` 주소를 교사 설정 **4단계 → 연결·배포 관리**에 붙여 넣고 **웹앱 주소 저장**을 누르세요. [Google 배포 안내](https://developers.google.com/apps-script/guides/web)

7. **챗봇 연결 확인**
   같은 **연결·배포 관리**에서 **챗봇 연결 확인**을 누르세요. 준비 상태에 남은 항목이 있으면 안내대로 확인하세요.

8. **99-999로 끝까지 체험**
   교사 설정의 **교사 미리보기**를 열고 자동으로 표시된 **99-999**로 시작하세요. 두 문항에 차례로 답하고, 보충 질문에는 지문의 근거를 말해 보세요. 두 문항의 답변 기록 완료 안내까지 확인하세요. 미리보기 기록은 실제 학생 평가에서 제외됩니다.

9. **일반 학생 입장 확인 후 안내**
   학생과 같은 접속 조건에서 **학생용 주소**를 열고, 시험용 반-번호와 참여코드로 입장되는지 확인하세요. 확인이 끝나면 **학생용 주소와 참여코드**를 함께 알려 주세요. 학생은 별도 답안지 없이 채팅으로 두 문항에 답합니다. 교사 미리보기 주소는 공유하지 마세요.

10. **문항별 평가 검수**
    시트의 **simbot → 3. 학생 현황·평가 검수**를 여세요. 각 문항의 실제 질문·학생 답변·자료 인용·AI 판단 이유를 확인하고, **교사 판단·피드백·학생 향상 방법**을 적어 문항별로 최종 확정하세요. **답변 분석** 버튼이 보이면 먼저 눌러 분석 초안을 확인할 수 있습니다.

자료·목표·성취기준·문항·평가 단계 수를 바꾸면 문항을 다시 확정하고 기준표를 다시 생성하세요. 기준 문구만 고쳤다면 검토 승인을 다시 체크하고 저장하면 됩니다. **다음·상태 새로고침은 저장 버튼이 아닙니다.**

배포자 확인: 연결 스크립트의 파일 13개와 시트 6개(시작하기·수업 자료·학생별 현황·질문과 답변·교사 평가·필수 평가 응답)를 확인하세요. 사본의 기록과 개인 스크립트 속성이 비어 있는지 확인하고, 운영본과 다른 수업 ID·참여코드를 사용하며 평가 승인을 해제한 뒤 전달하세요.
