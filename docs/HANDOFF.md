## 2026-08-25 (이어서) 1단계 — 카드 8종 타입 + 지역 생성기

`lib/questioning-cards.ts` 신설. DB 컬럼과 1:1로 맞춘 `ThinkingCardDraft`와, **AI 없이
지문에서 기계적으로 뽑는 카드 생성기**들. 배경·리서치·심화 카드는 지문 밖 지식이라
여기서 만들지 않는다(출처 없이 만들면 지어낸 카드가 된다).

- `buildVocabularyCards` — 어휘표 → 낱말 카드. 문맥 문장이 실제 본문에 있으면
  verified/1.0, 없으면 needs_review/0.6 (교사가 손으로 적은 뜻일 수 있음)
- `buildPassageCards` — 본문 문장을 사실/추론으로 나눔. 연결 표현(때문·반면·위해…)이
  있으면 추론 카드 + reasoningType, 나머지 중 핵심 개념이나 수치가 든 문장은 사실 카드
- `buildDialogueDesignCards` — **메모 한 줄 = 카드 한 장**. 의도 표(제목/낱말/까닭/근거/
  중심생각/경험/예측) 7종으로 기본 발문을 붙이고 needs_review로 남김
- `buildExpectedQuestionCards` — 시뮬레이션 질문을 라우터 카드로. 답을 담지 않고
  관련 카드로 잇는다
- `buildLocalCardSet` / `summarizeCardSet` / `formatCardSetSummary`

### 검증에서 잡은 것
1. **낱말 질문이 꺼져 있었다** — 연결 후보에서 낱말 카드를 빼고 사실·추론만 뒤져서,
   답할 수 있는 질문을 껐다. 후보에 낱말 카드 포함.
2. **까닭 질문이 엉뚱한 카드에 붙었다** — "왜 잔반이 줄었나요?"가 "잔반이 20kg으로
   줄었다"는 *사실* 카드에 연결. 관점별 라우팅 추가(낱말→낱말 카드, 까닭→cause_effect
   추론 카드, 사실확인→키워드 겹침이 가장 많은 사실 카드).
   키워드 겹침 폴백은 **사실 확인 관점에만** 쓴다. 전체에 쓰면 지문이 답할 수 없는
   질문까지 낱말 하나 겹친다고 "답 가능"으로 잘못 보고한다.
3. **확인 창 대상에 자동 카드가 섞였다** — `needsReview`를 확인 창 기준으로 쓰면
   낱말·예상 질문 카드 때문에 창이 매번 뜬다. `needsConfirmation`(대화설계·리서치만)과
   `weakCardCount`(숫자로만 알림)로 분리.
4. 의도를 못 알아본 메모 카드는 발문이 비어 있어 `isEnabled: false`. 교사가 채우기 전엔
   챗봇에 안 들어간다.
5. 자료가 비어 있으면 카드를 만들지 않는다(근거 없는 예상 질문만 쌓이는 것 방지).

## 2026-08-25 학생 챗봇 대화 품질 수정 5건

선생님이 실제 미리보기에서 대화해 보며 잡아낸 것들. 전부 **카드와 무관한 전달 방식의
문제**였다 — 챗봇은 답할 정보를 갖고 있었는데 엉뚱하게 내밀었다.

1. **`석 달이 뭐야?` → 낱말을 `달이`로 끊었다.** 정규식이 공백을 못 넘어 마지막
   토큰만 봤다. `resolveTermFromPhrase()` 신설 — 뒤에서부터 토큰을 1·2·3개씩 붙여
   조사를 뗀 뒤 **지문에 실제로 있는 표현**을 고른다. 긴 것부터 본다(`석 달` > `달`).
   내장 사전에 기간 표현(석 달·두 달·넉 달·보름) 추가.

2. **`석달?`처럼 낱말만 던지는 물음을 못 알아봤다.** `isBareTermQuestion` 추가 —
   낱말 하나 + 물음표이고 **아는 낱말일 때만** 어휘로 본다. 아무 짧은 말이나 어휘로
   보면 되물음·맞장구까지 뜻풀이가 나간다.

3. **말투가 섞였다** — "짚었군요"(존댓말) 다음에 "…말한다"(기사 문체).
   `quoteSourceSentence()` 신설. 기사 원문을 고쳐 쓰지 않고 `자료에는 "…"라고 나와
   있어요`로 감싼다. 이미 존댓말로 끝나는 문장(교사 작성 자료)은 그대로 둔다.

4. **질문을 "짚었군요"로 되받았다.** `양 선택제에 대해서 설명해 주세요` →
   `"양 선택제에 대해서 설명해 주세요"라고 짚었군요`. 묻는 아이를 무안하게 만든다.
   `asksRatherThanStates()` 추가. 물음표가 지워진 뒤에도 알아보도록 `되나요·까요·는지·
   ㄹ까` 등 어미로도 판정한다. 그리고 `X에 대해서 설명해 주세요`를 어휘 질문으로
   분류(`자료·기사·글` 등 글 전체를 가리키는 말은 제외).

5. **근거가 문장이 아니라 조각이었다** — `양 선택제·잔반 게시판 효과`는 표 제목이다.
   `looksLikeSentence()` 추가. 서술어로 끝나지 않거나 가운뎃점으로 항목만 나열한
   줄은 근거에서 뺀다. 목차를 내밀면 아이는 설명을 들은 게 아니다.
