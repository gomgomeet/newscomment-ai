# 평가 보드와 Notion 흐름 연결 방향

## 한 줄 방향

평가 보드는 **평가 실행본**이고, Notion은 **수업과 연수 맥락이 담긴 원본 문서**로 둔다.

교사는 Notion에 이미 만들어 둔 평가 설계와 응답 수집 흐름을 버리지 않는다. 대신 평가 보드가 그 링크와 내용을 읽어 평가 설계, 응답 수집, 채점, 피드백, 세특 생성으로 이어지는 실행 흐름을 만든다.

## 기본 운영 골격

평가 보드의 중심 흐름은 아래 순서로 고정한다.

```text
성취기준 선택
→ 평가 설계
→ 응답 수집
→ 채점표/루브릭 정리
→ 학생 응답 분석
→ 교사 피드백 입력
→ 과정 중심 평가 정리
→ 세특 생성
```

이 흐름에서 외부 도구는 보조 역할을 맡는다.

| 영역 | 기본 위치 | 역할 |
| --- | --- | --- |
| 성취기준과 평가 기준 | 평가 보드 | 평가의 기준과 활성 버전을 고정한다 |
| 수업/연수 흐름 | Notion | 교사가 만든 원본 맥락을 보관한다 |
| 학생 응답 수집 | 보드 링크 또는 Google Form 또는 Notion | 학생에게 배포되는 입구다 |
| 채점과 피드백 | 평가 보드 | 교사가 최종 판단을 확정한다 |
| 세특/성장 기록 | 평가 보드 | 확정된 평가 근거를 바탕으로 생성한다 |

## Notion을 붙이는 방식

Notion 연결은 "Notion을 메인 DB로 쓰기"가 아니다. 보드는 Notion 페이지를 아래처럼 해석한다.

```text
Notion 수업/연수 페이지 URL
→ 평가 설계 요소 추출
→ 응답 수집 링크 확인
→ 학생 결과물 데이터베이스 연결
→ 보드 단계에 임시 반영
→ 교사가 확인 후 활성 버전 생성
```

처음부터 완전 자동 확정을 목표로 삼지 않는다. 1차 버전은 **자동 반영 후 교사 확인**을 원칙으로 한다.

## 보드가 읽어야 하는 Notion 정보

보드는 Notion 페이지 또는 연결된 DB에서 다음 항목을 찾는다.

| 항목 | 보드 반영 위치 |
| --- | --- |
| 학년, 교과, 수업 주제 | 수업 맥락 |
| 성취기준, 평가 목표 | 성취기준과 평가 목표 |
| 평가 요소, 수준별 기준, 배점 | 채점표/루브릭 |
| Google Form, 보드 학생 링크, Notion 제출 링크 | 응답 수집 링크 |
| 학생 결과물 DB 또는 학생 페이지 | 학생 응답 분석 |
| 교사 관찰 메모, 피드백 원칙 | 교사 피드백과 과정 중심 평가 |

## 학생 배포 원칙

기본값은 **보드 자체 학생용 링크**다. 다만 이미 연수 흐름에서 Google Form 또는 Notion 응답 링크가 만들어진 경우, 그 링크를 보드에 연결해 그대로 사용한다.

학생 배포 패키지는 다음 요소를 가진다.

| 요소 | 설명 |
| --- | --- |
| 학생용 링크 | 응답을 제출하는 기본 경로 |
| QR | 교실 화면 또는 인쇄물 배포용 |
| 수업 코드 | QR 접근이 어려운 학생을 위한 대체 경로 |
| 마감/재제출 설정 | 수업 운영 조건 |
| 응답 현황 | 제출 여부와 가져오기 상태 |

## 1차 구현 범위

현재 구현된 평가 준비 보드를 먼저 수정한다.

1. 평가 설계 화면은 성취기준, 평가 목표, 루브릭 3단계만 보이게 한다.
2. 학생 배포, 응답 수집, 자동 채점, 교사 피드백, 생기부 기록은 별도 운영 대시보드로 분리한다.
3. Notion 수업/연수 페이지 URL과 응답 수집 링크는 운영 흐름에서 관리한다.
4. 학생 결과물 DB URL과 기존 Notion 읽기 설정을 유지한다.
5. Notion 설정을 다시 저장하거나 학생 결과물을 가져와도 원본 페이지 링크와 응답 수집 링크가 사라지지 않게 한다.

## 현재 반영된 화면 분리

| 화면 | 역할 |
| --- | --- |
| `/dashboard/prep/[prepId]` | 평가 설계. 1단계 수업 맥락, 2단계 성취기준과 평가 목표, 3단계 평가 기준만 다룬다 |
| `/dashboard/evaluation` | 평가 운영. 학생용 질문지·수정 링크 배포, 자동 채점, 교사 피드백, 생기부 기록 이동을 다룬다 |
| `/dashboard/projects/[projectId]` | 결과물 연결과 실제 채점 작업. Notion 결과물 읽기, 수동 입력, AI 초안 생성, 교사 확정을 다룬다 |
| `/dashboard/growth` | 확정 평가를 바탕으로 성장 기록과 생기부 문장으로 정리한다 |

## 이후 구현 계획

### 2차: Notion 페이지 자동 분석

- Notion 페이지 본문 읽기
- 학년, 교과, 성취기준, 평가 목표 후보 추출
- 응답 수집 링크 후보 탐지
- 교사에게 "보드에 반영" 전 확인 화면 제공

### 3차: 학생 배포 패키지

- 보드 자체 학생 응답 페이지 생성
- QR 생성
- Google Form 또는 Notion 링크를 대체 배포 경로로 관리
- 제출 현황과 가져오기 상태 표시

### 4차: 채점 이후 세특 흐름

- AI 초안 채점과 교사 확정 분리
- 교사 피드백 입력 상태 표시
- 성장 기록 보드와 연결
- 학생별 세특 초안 생성

## 중요한 제품 원칙

- Notion 원본에는 평가 결과를 자동으로 덮어쓰지 않는다.
- 교사가 확인한 활성 버전만 실제 평가 기준이 된다.
- AI는 평가를 돕지만 최종 평가는 교사가 확정한다.
- 링크 연동보다 평가 파이프라인이 우선이다.
- 보드는 "어디까지 했는지"와 "다음에 무엇을 해야 하는지"를 먼저 보여준다.
