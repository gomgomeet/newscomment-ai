# 연수용 Claude 스킬 배포 안내

「노션×Claude로 완성하는 과정중심평가」 2차시 실습에 필요한 **평가 스킬**을 수강생에게
나눠 주는 방법이다. 노션 커넥터·플러그인은 이미 설치된 상태를 전제로, **스킬만** 얹는다.

## 1. 나눠 줄 파일

`npm run skills:package` 를 실행하면 `dist/skills/` 에 ZIP이 만들어진다.

| 파일 | 쓰는 차시 | 하는 일 |
| --- | --- | --- |
| `nie-notion-assessment.zip` | **2차시 (필수)** | 자동채점 초안 → 교사 검수 → 승인 후 Notion 저장 |
| `edu-rubric.zip` | 1차시 (선택) | 성취기준에서 루브릭·자기평가 체크리스트 설계 |

2차시만 진행한다면 `nie-notion-assessment.zip` **한 개만** 배포한다.
파일 수가 늘수록 설치 단계에서 이탈하는 수강생이 늘어난다.

> ⚠️ ZIP을 **풀어서** 나눠 주지 않는다. claude.ai 업로드는 ZIP 파일을 그대로 받는다.
> 카카오톡·메신저로 보내면 압축이 풀리거나 이름이 바뀔 수 있으므로 **다운로드 링크**로 준다.

## 2. 수강생 환경을 먼저 조사한다

연수 시작 전 설문이나 거수로 확인한다. **경로가 섞이면 설치 안내가 무너진다.**

| 환경 | 배포 경로 | 설치 방식 |
| --- | --- | --- |
| 일반 Claude 웹·데스크톱 앱 | **A** | ZIP 업로드 |
| Claude Code (터미널) | **B** | 압축 풀어 폴더에 넣기 |
| Cowork | **C** | claude.ai 계정에 올린 스킬이 자동 동기화 |
| 기관에서 외부 연결 차단 | **D** | 스킬 없이 복사·붙여넣기로 같은 절차 완주 |

### 요금제도 함께 조사한다 (스킬 업로드는 무료 플랜에서 막힐 수 있다)

환경만 묻고 요금제를 안 물으면 당일에 무너진다. 설문에 **"Claude 유료 플랜(Pro 이상)을
쓰시나요?"** 를 반드시 넣는다.

| 항목 | 무료 플랜 | Pro 이상 |
| --- | --- | --- |
| Notion 커넥터(MCP) 연결 | 가능하되 **커넥터 1개 제한**으로 알려짐 | 제한 없음 |
| 커스텀 스킬 ZIP 업로드 | **불가로 알려짐** | 가능 |

즉 **무료 계정 수강생은 노션 연결은 되어도 스킬은 못 올릴 가능성이 크다.** 이들에게는
처음부터 **경로 D(복사·붙여넣기)** 를 기본으로 배정하고, 스킬 설치 시간에 다른 활동을
주는 편이 낫다.

> ⚠️ 위 두 줄은 2026년 8월 기준으로 확인한 내용이며 **1차 출처(Anthropic 도움말)에
> 직접 접근하지 못한 상태에서 정리했다.** 요금제 정책은 자주 바뀌므로, 연수 전에
> **무료 계정 하나를 실제로 만들어 스킬 업로드 메뉴가 보이는지 직접 확인한다.**
> 이 확인 한 번이 당일 20분을 아낀다.

### 스킬과 MCP는 별개 레이어다

수강생이 가장 많이 헷갈리는 지점이다. **둘 다 있어야 2차시가 돌아간다.**

| 층 | 무엇인가 | 없으면 |
| --- | --- | --- |
| **커넥터(MCP)** | Notion을 읽고 쓰는 통로 | Claude가 Notion 페이지에 접근하지 못함 |
| **스킬** | 그 통로를 어떤 순서·규칙으로 쓸지 알려 주는 업무 매뉴얼 | 접근은 되지만 평가 절차·안전 게이트가 매번 달라짐 |

스킬을 올렸는데 Notion을 못 읽는다면 커넥터 문제이고, Notion은 읽는데 교사 승인 없이
저장하려 든다면 스킬 문제다. 증상으로 원인을 나눠 안내한다.

## 3. 경로 A · Claude 웹/데스크톱 (ZIP 업로드)

가장 많은 수강생이 여기에 해당한다.

1. 수강생이 `nie-notion-assessment.zip` 을 **다운로드**한다.
2. 데스크톱 앱은 사이드바 **Customize**, 웹은 **설정의 스킬(Skills) 화면**을 연다.
3. 스킬 업로드를 선택하고 받은 ZIP을 그대로 올린다.
4. 목록에 `nie-notion-assessment` 가 보이고 **켜져(enabled) 있는지** 확인한다.
5. 새 대화에서 작동을 확인한다(§6).

> 메뉴 이름과 위치는 업데이트에 따라 달라진다. 핵심은
> **설정 → 스킬 → ZIP 업로드 → 활성화** 네 단계다.

**미리 확인할 것**
- 커스텀 스킬 업로드가 가능한 요금제인지 (§2 — 무료 플랜은 막힐 가능성이 크다)
- 기관 계정이면 관리자가 스킬 기능을 켜 두었는지
- 연수 전 **강사가 자기 계정으로 한 번 끝까지 올려 본다.** 당일 첫 시도는 금물이다.

## 4. 경로 B · Claude Code (압축 풀어 넣기)

ZIP을 풀어 폴더째 옮기면 끝이다. 재시작 없이 바로 인식된다.

```bash
mkdir -p ~/.claude/skills
unzip nie-notion-assessment.zip -d ~/.claude/skills/
# 결과: ~/.claude/skills/nie-notion-assessment/SKILL.md
```

- 개인 전체에 적용: `~/.claude/skills/<스킬이름>/SKILL.md`
- 특정 프로젝트에만 적용: 그 저장소의 `.claude/skills/<스킬이름>/SKILL.md`
- 확인: 세션에서 `/skills` 또는 `/nie-notion-assessment`

세션 도중에 넣어도 인식되지만, `~/.claude/skills/` 폴더 자체를 **새로 만든** 경우에는
Claude Code를 한 번 재시작한다.

이 저장소로 실습한다면 아예 `.claude/skills/` 에 커밋해 두는 방법도 있다.
그러면 저장소를 받은 사람 모두가 설치 없이 같은 스킬을 쓴다.

## 5. 경로 C · Cowork

Cowork 세션은 **내 컴퓨터의 `~/.claude/skills/` 를 읽지 않는다.** 세션 시작 시점에
**claude.ai 계정에 켜 둔 스킬**을 동기화해 온다.

따라서 Cowork 수강생은 **경로 A로 claude.ai에 먼저 올리고 활성화한 뒤** Cowork 세션을
새로 시작한다. 이미 열린 세션에는 반영되지 않는다.

## 6. 설치 확인 (수강생이 직접 하는 30초 점검)

새 대화에서 그대로 입력한다.

```
지금 사용할 수 있는 스킬 목록을 보여 줘.
nie-notion-assessment 스킬이 있으면, 그 스킬이 저장 전에 반드시 하는 일 3가지만 말해 줘.
아직 Notion은 검색하지도 수정하지도 마.
```

**통과 기준** — 답에 아래가 모두 나온다.
- 읽기 먼저 / 한 건 시험
- 저장 전 `현재값 → 새값` 미리보기
- 교사의 명시적 승인 후에만 저장

이 세 가지가 안 나오면 스킬이 안 붙은 것이다. 활성화 여부부터 다시 본다.

## 7. 배포 수단

| 수단 | 장점 | 주의 |
| --- | --- | --- |
| 학교 업무포털·클래스룸 자료실 | 기관 내 신뢰, 접근 통제 | 외부 강사는 권한이 없을 수 있음 |
| Google Drive 공유 링크 + 단축 URL/QR | 준비가 가장 빠름 | "링크가 있는 모든 사용자" 권한 확인 |
| GitHub 저장소 파일 링크 | 버전 관리가 됨 | 비개발자에게 다운로드 위치가 헷갈림 |
| USB | 인터넷 장애에 강함 | 회수·보안 관리 필요 |

**권장** — 메인은 QR(구글 드라이브), 백업은 USB. 연수장 와이파이는 자주 막힌다.

> 🔒 ZIP 안에 **토큰·워크스페이스 인증정보·실제 학생 자료를 절대 넣지 않는다.**
> 스킬은 절차만 담고, Notion 인증은 수강생 각자가 OAuth로 한다.

## 8. 수강생 안내 문구 (그대로 읽어 주기)

> 지금부터 3분간 스킬을 설치하겠습니다. 화면의 QR을 찍어 파일을 **다운로드만** 하세요.
> 압축은 풀지 마세요. Claude 설정에서 스킬 화면을 열고, 방금 받은 zip 파일을 그대로
> 올린 뒤 목록에 `nie-notion-assessment`가 켜져 있는지 확인합니다.
> 다 되신 분은 새 대화를 열고 화면의 확인 문장을 붙여 넣어 주세요.
> **설치가 안 되셔도 실습은 그대로 진행합니다.** 제가 익명 원문을 채팅창에 드리면
> 같은 절차를 복사·붙여넣기로 완주할 수 있습니다.

마지막 문장을 반드시 넣는다. 설치 실패한 수강생이 실습에서 이탈하지 않게 하는 장치다.

## 9. 자주 나는 문제

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| 업로드가 오류로 거부됨 | frontmatter에 허용되지 않은 키가 있음 | `npm run skills:package` 로 다시 만든다. 검사기가 잡아 준다 |
| 스킬 메뉴가 안 보임 | 무료 플랜이거나 기관 관리자가 차단 | 경로 B(Claude Code)나 경로 D(복붙)로 전환 |
| 커넥터를 추가하니 다른 연결이 끊김 | 무료 플랜의 커넥터 1개 제한 | 연수 중에는 Notion만 연결하도록 안내 |
| 올렸는데 반응이 없음 | 활성화(토글)를 안 함 | 목록에서 켠 뒤 **새 대화**에서 재시도 |
| Cowork에서 스킬이 없다고 함 | 세션 시작 후에 올림 | claude.ai에서 켜고 세션을 새로 시작 |
| 압축을 풀어서 올림 | 폴더를 올림 | 원본 ZIP 파일을 다시 받아 올림 |
| 스킬은 붙었는데 Notion을 못 읽음 | 스킬과 커넥터는 별개 | 커넥터 연결·OAuth·권한 범위를 확인(사전 준비 문서) |

## 10. 만들 때 지켜야 하는 규격 (강사·제작자용)

claude.ai 업로드와 Claude Code에 **모두** 통하려면 아래를 지킨다.
`scripts/package-skills.mjs` 가 패키징 전에 전부 검사한다.

- ZIP 안에 **스킬 이름 폴더 하나**, 그 안에 `SKILL.md` (또는 ZIP 루트에 `SKILL.md`)
- 압축 해제 크기 **30MB 미만**
- `name`: **64자 이하, 소문자·숫자·하이픈**, 예약어 `anthropic`·`claude` **사용 불가**
  (그래서 이 스킬 이름은 `claude-...`가 아니라 `nie-notion-assessment` 다)
- `description`: **1024자 이하, 비어 있으면 안 됨**
- frontmatter는 **`name`, `description`, `license`, `compatibility`, `metadata`,
  `allowed-tools` 여섯 개만.** `argument-hint`, `model`, `context` 같은 Claude Code 전용
  키가 하나라도 있으면 업로드가 **무시가 아니라 오류로 실패**한다
- 본문에서 Claude Code 전용 문법(`` !`명령` `` 동적 주입, `@파일` 참조,
  `${CLAUDE_PROJECT_DIR}` 치환)을 쓰지 않는다. claude.ai 대화에서는 작동하지 않는다

## 11. 강사 사전 점검

- [ ] `npm run skills:package` 가 오류 없이 통과한다
- [ ] 강사 본인 계정에 ZIP을 올려 §6 확인 문장이 통과한다
- [ ] 수강생 환경(웹/Code/Cowork)과 **요금제(무료/유료)** 를 미리 조사했다
- [ ] **무료 계정으로 스킬 업로드 메뉴가 보이는지 직접 확인했다**
- [ ] 다운로드 링크와 QR이 다른 기기에서도 열린다
- [ ] USB 백업본을 준비했다
- [ ] 설치 실패자용 **익명 원문 + 승인된 루브릭** 복붙 자료를 준비했다
- [ ] 연수 종료 후 커넥터 해제·권한 정리 안내를 준비했다
