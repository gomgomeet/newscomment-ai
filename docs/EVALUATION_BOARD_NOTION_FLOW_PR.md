# PR: 평가 보드에 Notion 수업 흐름과 응답 수집 링크 연결

## Summary

- 평가 보드의 기본 골격을 `평가 설계 → 응답 수집 → 채점 → 피드백 → 세특 생성` 흐름으로 정리한다.
- Notion을 평가 결과 저장소가 아니라 수업/연수 원본 맥락으로 두고, 보드가 필요한 항목을 읽어 실행 흐름에 반영하도록 한다.
- 현재 평가 준비 보드에 Notion 수업/연수 페이지 URL, 응답 수집 링크, 학생 결과물 DB URL을 함께 관리하는 UI를 추가한다.

## Why

기존 흐름은 Notion 결과물 읽기와 Claude/Notion 연결 자체에 무게가 실리면서, 교사가 실제로 끝내야 하는 평가 과정이 흐려질 위험이 있었다.

이번 방향은 외부 연결을 중심에 두지 않고, 평가 보드 안에서 교사의 평가 업무 순서를 먼저 고정한다.

```text
노션 연수/수업 흐름
→ 평가 설계 불러오기
→ 응답 수집 링크 연결
→ 채점표/루브릭 정리
→ 학생 응답 분석
→ 교사 피드백 입력
→ 과정 중심 평가 정리
→ 세특 생성
```

## Current Scope

- `assessment_preps.notion_config` JSON 안에 다음 값을 저장한다.
  - `source_page_url`: Notion 수업/연수 원본 페이지
  - `response_collection_url`: 학생 응답 수집 링크
  - `database_url`: 학생 결과물 데이터베이스
- 평가 준비 상세 화면은 `평가 설계`로 정리하고 1~3단계만 보여준다.
- `/dashboard/evaluation`을 `평가 바로 하기` 운영 대시보드로 만든다.
- 운영 대시보드에서 학생용 질문지·수정 링크, 자동 채점, 교사 피드백, 생기부 기록 상태를 보여준다.
- Notion 학생 결과물 가져오기 후에도 `source_page_url`, `response_collection_url`이 보존되도록 한다.

## Product Decisions

- Notion 원본은 읽기 전용이다.
- 평가 결과와 활성 평가 기준은 앱 DB에 남긴다.
- 자동 추출 결과는 교사가 확인한 뒤 반영한다.
- Google Form은 기본값이 아니라 응답 수집 링크 옵션이다.
- 보드 자체 학생 링크를 최종 기본 배포 방식으로 발전시킨다.
